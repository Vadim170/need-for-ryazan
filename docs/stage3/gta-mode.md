# GTA-режим: пешком, угон, преступления и полиция

Аркадный, без крови. Включён по умолчанию; `?gta=0` — старый режим «только машина», `?police=0` — без розыска и полиции,
`?player_char=<id>` — персонаж игрока (id из `public/assets/people/people.json`, по умолчанию `man_jacket`).

## Управление
| Действие | Клавиатура/мышь | Геймпад |
|---|---|---|
| Сесть / угнать / выйти (на скорости > 25 км/ч — выпрыгнуть) | F | Y |
| Идти / бег / шагом | WASD / Shift / Alt | левый стик / X (удерживать) |
| Камера (клик по канвасу — захват мыши, Esc — отпустить) | мышь | правый стик |
| Прыжок; у препятствия — перелезть / забраться (на спринте низкое — само) | Пробел | A |
| Удар / выстрел; прицел | ЛКМ; ПКМ | B, RT; LT |
| Пинок | V | крестовина ↓ |
| Ограбить прохожего / открыть багажник ДПС | E | крестовина ↑ |
| Перезарядка (пешком) | R | — |
| Оружие: следующее / выбор / колесо | колесо мыши, Q / 1–4 / Tab (удерживать) | LB, RB |
| Сирена (в машине ДПС) | G | R3 |
| Сброс машины | R (за рулём) | Back/View (было Y) |

## Архитектура
- `src/player/gta.ts` — `GtaMode`: сборка всего, `preFrame` (ввод, до физики) и `postFrame` (после физики) из `main.ts`;
  `focus` (стриминг, тени, пешеходы), `vehicle` (машина для звука/спидометра/фар/погоды).
- `src/player/player.ts` — игрок: состояния `driving → exiting → foot → entering (подойти к двери → «сесть») → driving`,
  `down` (рэгдолл, встаёт), `dead`/`busted` (надпись, респаун). Здоровье/броня, деньги, инвентарь, преступления.
- `src/player/character-body.ts` — капсула на `KinematicCharacterController` Rapier: autostep 0.45 м (ступени, крыльца,
  бордюры), склоны до 50°, прилипание 0.35 м. Коллайдер — membership 0x0020, filter 0 (машины не упираются в человека, контактов
  и событий ломаемых пропсов от капсулы нет; удары машин по людям считаются вручную по OBB). Машины для человека — неподвижная
  стена: встроенные импульсы KCC выключены, свой толчок — только лёгким динамическим телам ≤ 300 кг (урны, лавки, обломки).
  `teleport` сразу переносит и коллайдер (`propagateModifiedBodyPositionsToColliders`), `groundSpeed` — фактическая скорость
  капсулы (темп шагов модели).
- `src/player/human-rig.ts` — человек с позой на CPU (тот же MakeHuman-персонаж и CMU-клипы): локомоция idle → walk → run →
  jog → sprint по скорости с общей фазой шага; переходы — вокруг естественных скоростей клипов (длина цикла / длительность:
  walk 1.6, run 2.7, jog 3.8, sprint 6.5 м/с), темп = скорость / смешанная длина цикла (как у пешеходов). Бег 4.6 м/с — jog в
  1.2× (3.5 шага/с; раньше run в 1.7× — 4.5 шага/с, «семенил»), спринт 7.2 м/с — sprint. Веса — по сглаженной скорости, темп —
  по фактической скорости капсулы (упёрся — ноги не бегут на месте). Прыжок/полёт, удары верхом тела поверх ходьбы,
  процедурное прицеливание (руки на цель по тангажу камеры, ПМ двумя руками / автомат у плеча), «сесть», лежать, рэгдолл
  (`RigRagdollSkin`). Один draw call (+тень) на человека. Игрок (`player.ts`): резкий разворот — сначала поворот, потом разгон
  (без «лунной походки»), высота модели догоняет ступени/бордюры за ~0.1 с (autostep не «щёлкает»).
- `src/player/rig-assets.ts` — загрузка `people.json` + `clips.bin` пешеходов и **отдельных клипов игрока**
  `public/assets/player/clips.bin` (sprint 143_01, jump 13_39, punch 02_05, kick 74_03, jog 16_45 — CMU, сборка
  `python3 -I assets/scripts/people/build_player_clips.py assets/downloads/cmu/bvh game/public/assets/player`; BVH — зеркало
  `github.com/una-dinosauria/cmu-mocap`, файлы идентичны cgspeed). Клипы пешеходов не тронуты.
- `src/player/fleet.ts` — машины игрока: Largus, угнанные из трафика (поза и скорость переносятся, вариант кузова — тот же, что
  рисовал трафик: `TrafficRenderer.variantFor` / glTF `GltfTrafficLayer.modelFor`), с парковки (`Props.findParkedCar /
  takeParkedCar`, `car_p_<пресет>` → `allVariants()`), полицейские. Каждая — `Vehicle` с конфигом класса
  (`src/vehicle/classes.ts`: масса, пружины/тормоза/моменты по массе; легковые, ДПС, внедорожник, ГАЗель, автобус, троллейбус).
  Брошенная машина стоит на ручнике и снова берётся; дальше 320 м исчезает (кроме Largus и последней машины игрока —
  на неё ссылаются звук/погода/HUD). Спавн: высота — по физической земле под 4 колёсами (`groundSnap`), без вертикальной
  скорости; угнанная из трафика — её кинематическое тело сначала удаляется из мира (`TrafficPhysics.takeOver`). Троллейбус вне сети (маршруты
  `trolleybus` трафика, сетка 20 м) едет от аккумулятора (АХ в HUD), с проводами заряжается.
- `src/vehicle/vehicle-visuals.ts` — модель любой машины одним экземпляром с шейдером трафика (фары, стоп, маячок ДПС).
- `src/combat/` — `weapons.ts` (кулаки, ПМ, АКС-74У, дробовик), `combat.ts` (хитскан: луч Rapier + капсулы людей; рукопашная
  по сектору), `effects.ts` (трассеры, вспышки + одна общая лампа, искры/пыль, дым/огонь, взрывы; 4 draw call), `vehicle-damage.ts`
  (здоровье машин: дым < 60, чёрный < 30, огонь ≤ 10, через 5 с — взрыв; удары по резкому Δv; трафик — по id, при «смерти»
  становится обломком), `pickups.ts` (деньги, оружие, бронежилет, аптечка), `weapon-meshes.ts`, `events.ts`.
- `src/police/` — `wanted.ts` (жар → 0–5 звёзд; свидетели: полиция — сразу, прохожие в 30 м — «звонок» через 2–5 с; потеря
  звезды вне видимости 10+5·уровень с), `police.ts` (машины ДПС: сначала перехват машин ДПС из трафика, иначе спавн на дороге вне
  кадра в 110–190 м; бот `ai-driver.ts` по A* `road-router.ts`; высадка по двое; 1★ — задержание, 2★+ — ПМ, 3★+ — таран, 4★+ —
  автомат/дробовик), `cop.ts`.
- `src/camera/orbit-camera.ts` — камера пешком: орбита, прицел через правое плечо, столкновение луча с домами/пропсами/машинами.
- `src/hud/gta-hud.ts` — деньги, звёзды (мигают при поиске), оружие/патроны, здоровье/броня, подсказки, «ПОТРАЧЕНО»/«АРЕСТОВАН»,
  прицел, колесо оружия, полоса задержания. Миникарта: метки полиции (`Minimap.blips`).
- Респаун: `public/assets/gta/places.json` (больницы, отделы полиции, автосервисы из OSM, `pipeline/build_places.py`; вне
  `public/world/`, т.к. сборка мира его перезаписывает). Смерть — больница (−100 ₽ −10 %), арест — отдел полиции (−50 ₽ −20 %);
  оружие и броня теряются, розыск снят. Вода: плавать нельзя — 1.2 с в воде = «утонул».

Правки в общих файлах (точечные): `core/input.ts` (`pad`, `isDown`, `padPressed`; сброс машины на Back вместо Y),
`physics/world.ts` (`offPreStep`, `untrack`), `vehicle/vehicle.ts` (`dispose`, `VehicleLights`, `setModel` для любой модели,
коллайдер по высоте покоя — для Largus без изменений), `traffic/index.ts`/`physics.ts` (`setPlayer`, `crashVehicle`; пешком удар не
разбивает машину трафика), `traffic/render.ts` (`variantFor`), `traffic/gltf-models.ts` (`modelFor`), `rail/*` (`setPlayer`),
`people/people-system.ts` (`forEachAgent`, `strike`, `panic`, `flee`, `spawnAt`, `anger`, `stepToward`, `isDown`…),
`world/props.ts` (`findParkedCar`, `takeParkedCar`; `queryObstacles` пропускает сломанные), `world/city-world.ts` (`surfaceAt`),

## Посадка, выход, игрок у машин (разбор багов плейтеста)
- **Машину подбрасывало при угоне из трафика.** Кинематическое тело трафика оставалось на месте новой машины: Rapier
  обновляет запросы сцены (лучи) только в `world.step`, и выключенный/уведённый коллайдер ещё виден лучам. Лучи подвески
  нового `Vehicle` на первом шаге били в крышу «призрака», подвеска сжималась до упора → +0.65 м/с вверх (до ограничения силы
  подвески — сильнее). Теперь `Fleet.fromTraffic` → `TrafficPhysics.takeOver(v)`: тело удаляется из мира (это видно сразу),
  слот получает новое. Машины парковки так не страдали — их статический коллайдер удаляется (`takeParkedCar`) до спавна.
- **После выхода из машины/телепорта человек проваливался ~0.15 м в землю и застревал/дёргался.** `CharacterBody.teleport`
  ставил тело, а коллайдер оставался на старом месте до шага; первый запрос KCC шёл от старой позы (сиденье, точка над машиной),
  прилипание к земле давало mv.y до −0.35 м, и его прибавляли к новой позе. Теперь `propagateModifiedBodyPositionsToColliders()`.
- **Бег в стоящую машину ронял игрока.** `checkVehicleHits` брал |v машины − v игрока| > 3.5 м/с — бег 4.6 / спринт 7.2 м/с в
  борт стоящей машины = «сбит». Теперь сбивает только едущая машина (> 2.5 м/с) скоростью сближения по нормали ближайшей грани
  OBB. KCC больше не толкает машины (стоящая отъезжала на 0.2 м со скоростью ~1 м/с). Машины парковки от человека не ломаются
  (капсула без контактов/событий).
- Проверка (Chrome, `__game.frame`, `?police=0`): посадка/выход Largus, 2 машины трафика (ГАЗель), 2 машины парковки, ДПС —
  макс. вертикальная скорость кузова после посадки ≤ 0.03 м/с (было 0.65 у трафика), осадка ≤ 3 см; бег/спринт в борт
  и вдоль машины — игрок на ногах, машина сдвинута < 1 см; ноги после выхода на земле (+0.02 м — зазор KCC).
- Не исправлено (клип): `sprint` (143_01, запись 0.84 с, замыкание цикла с ошибкой 0.23) — правая стопа в опоре скользит
  (~1.7 м/с при 7.2 м/с); нужен другой спринт-клип подлиннее.

- **«Не угоняется стоящая машина — зависает».** Дверь водителя у машины в плотном ряду парковки оказывалась внутри соседней
  машины: автопилот к двери упирался и 5 с «висел», потом отменял посадку. Теперь `Fleet.doorFor` проверяет место у двери
  (шар 0.3 м, `intersectionWithShape`) и берёт другую сторону (пассажирская дверь), а автопилот садит в машину сразу, если
  0.4 с нет приближения к двери или прошло 2 с (дальше 4 м — отмена).
- **«В некоторые машины не сесть».** Проверено «до/после»:

  | Машина | до | после |
  |---|---|---|
  | парковка, процедурные (Granta, Vesta, Solaris, Niva, Duster, Creta, Camry, Kalina, X-Ray, Polo, Octavia…), свободный подход | да | да |
  | парковка в плотном ряду (соседи в 0.5 м) | «висит» у борта 5 с, отмена | да (другая дверь / сразу) |
  | парковка glTF (Largus, УАЗ-452) | да | да |
  | парковка, сдвинутая ударом (динамическое тело) | нет (не искалась) | да (`findParkedCar` смотрит обломки-машины) |
  | парковка вне LOD0 / у границы тайла | да | да |
  | трафик: седан, хэтчбек, универсал, внедорожник, такси, ДПС, ГАЗель | да | да |
  | трафик: ПАЗ, ЛиАЗ, троллейбус (дверь в 5 м от центра) | подсказка только у центра (расстояние от центра) | да (расстояние до габарита) |
  | трафик заглохший/сдвинутый (аварийка) | нет (`crashed` пропускались) | да (`TrafficPhysics.takeOver` убирает и динамическое тело) |
  | свои брошенные, угнанные и брошенные, ДПС флота | да | да |
  | сгоревшие (взорвались) | нет | нет (намеренно) |
- **«После выхода из машины меня не видно».** При «выпрыгнуть на ходу» (> 25 км/ч) рэгдолл запоминал скин относительно
  матрицы меша, а в машине меш не обновлялся (невидим) — тело рисовалось там, где игрок садился в машину (на десятки–сотни
  метров позади), пока рэгдолл не вставал. Теперь `launchRagdoll` сначала ставит позу/матрицу в текущее место
  (`rig.update(0)`); страж в `postUpdate`: пешком меш всегда видим и в сцене. Проверка: 30 выходов подряд (стоя, 5 м/с,
  15 м/с с рэгдоллом, после «телепорта» машины) — смещение отрисованного таза от игрока/тела рэгдолла ≤ 0.1 м (было 40 м).
- **Одежда полицейских и других на `HumanRig`.** 8 регионов тона, как у пешеходов (верх, низ, обувь, волосы, шапка,
  внутренний верх, шарф, перчатки): `RigLook.shoes/inner/scarf/gloves`; полиция — форма (`COP_LOOK`), не заданные —
  из палитр пешеходов; свой персонаж игрока (`player_me*`) — обувь и перчатки со своей текстуры.

## Перелезть / забраться (`src/player/climb.ts`)
Пробел у препятствия впереди (по направлению движения или взгляда); на спринте низкий забор перемахивается сам.
Подсказка в HUD: «Пробел — перелезть / забраться».
- Разбор лучами Rapier (группы персонажа; лёгкие динамические ≤ 300 кг — не препятствие): горизонтальные лучи 0.35…2.45 м
  → ближняя грань и первая свободная высота; луч вниз за гранью → верх (H над ногами); лучи вниз дальше через 0.15 м →
  толщина. Тонкое (≤ 0.75 м): H 0.45–1.1 м — перемахнуть (vault, ~0.6 с, опора руками), 1.1–2.2 м — перелезть (climb,
  1.4–1.8 с: подтянуться руками вверх, закинуть ноги, спрыгнуть); за ним земля не ниже 2.5 м и свободное место для капсулы.
  Толстое (крыльцо, контейнер, машина) H ≤ 1.6 м — забраться наверх (ledge). Выше 2.2 м / нет места — нельзя.
- Движение: капсула выключена (без столкновений с препятствием), ноги идут по сценарной траектории (пока ноги ниже верха,
  центр не заходит за грань); в конце — `teleport` на проверенное свободное место. Камера следует за ногами как обычно.
- Анимация не зависит от меша: `HumanRig.reach` ('plant' / 'up') — направления костей рук, `airborne` — поза прыжка.
- Пешеходы и полиция не лазают.
- Проверка (Chrome, `__game.frame`): забор 1.8 м — 5 секций × 2 стороны, все перелезли (climb); газонная ограда 0.66 м —
  3 × 2 по Пробелу и 2 × 2 сам на спринте (vault); машина парковки — забрался на крышу (ledge); контейнер 2.2 м — нельзя;
  после приземления — по другую сторону, ноги на земле (+0.02 м), капсула ни с чем не пересекается.

## События (для звука, `src/combat/events.ts`)
`gameEvents.on(type, fn)` или `window.__game.gta.events`: `gunshot` {weapon, x,y,z, byPlayer}, `impact` {surface}, `punch`
{hit, kick}, `footstep` {speed, surface — код SURF}, `jump`, `land` {speed}, `carDoor` {open}, `siren` {id, on}, `explosion`,
`dryFire`, `reload`, `weaponSwitch`, `pickup`, `wanted` {level, prev}, `scream`, `wasted`, `busted`, `respawn`.
Непрерывные сирены — опрос `__game.gta.police.sirens()` (позиция и скорость каждой). Пешком `audio.update` по-прежнему получает
`car` — последнюю машину (двигатель на холостых); различать можно по `__game.gta.player.state`.

## Отладка
`__game.gta.state()`, `.police.debug()`, `.give('rifle', 90)`, `.wanted(3)`, `.god()`, `.damage()`, `.carAt('paz')`;
ввод для тестов в скрытой вкладке: `__game.gta.ctl.override = { enter: true }` (разовые поля сбрасываются), `{ my: 1 }`,
`{ aim: true, firePressed: true }`, затем `__game.frame(1/60, t)`. Проверено в Chrome: выйти из машины, ходьба, посадка в
Largus/машину с парковки, угон машины трафика (водитель вылетает рэгдоллом), звёзды, высадка ДПС и стрельба, нокаут
полицейского (рэгдолл) и подбор ПМ, багажник ДПС (дробовик + бронежилет), угон машины ДПС, подрыв машины, смерть и респаун.
Стоимость GTA-слоя — ~0.4–0.6 мс/кадр (`state().ms`).

## Известные ограничения
- Машина с парковки нового пресета, которого нет среди вариантов трафика, рисуется пресетом-эталоном вида.
- Водитель в салоне не виден (персонаж скрыт), посадка — короткая анимация «сесть» от двери к сиденью.
- Пешеходы не дерутся всерьёз: 30 % выброшенных водителей идут на игрока и бьют (слабо).
- Полиция объезжает препятствия просто (ручник/задний ход), пешие полицейские идут по прямой с обходом вбок.
- Поезд водить нельзя (не сделано — отдельная задача).

## Бэклог: чего не хватает миру для игры пешком (не делалось)
- **Интерьеры и двери**: подъезды, магазины, кафе — сейчас глухие фасады; нужны хотя бы тамбуры/входные группы и
  «телепорт-двери» в простые интерьеры; двери машин не открываются визуально.
- **Коллизии пропсов**: у лавочек, урн, кустов, детплощадок, цветников, киосков-террас коллайдеров нет — проходим насквозь;
  ограды — боксы без калиток; деревья — только ствол.
- **Лазание/паркур**: перелезть через забор/ограду/лавку и забраться на уступ ≤ 1.6 м (крыльцо, капот/крыша машины) — есть
  (`src/player/climb.ts`); нет зацепов выше 2.2 м (гаражи, балконы), крыш с доступом, лестниц.
- **Ступени и рельеф у домов**: OSM-ступени и крыльца есть не везде; цоколи/приямки, пандусы, бордюры местами — щели между
  тротуаром и стеной (коллайдер здания vs рельеф), подземные переходы без проходов.
- **Плотность уличной мебели**: мало столбиков, знаков, рекламных стоек, ларьков, мусора, припаркованных велосипедов,
  остановочных павильонов во дворах; дворы пустоваты (гаражи-«ракушки», сушилки, скамейки у подъездов).
- **LOD вблизи**: фасады с 1–2 м выглядят плоско (нет рельефа окон/подоконников, дверей подъездов, домофонов, табличек с
  номерами); асфальт/плитка без деталей у ног (люки, трещины, лужи), трава/газон с камерой на 1.6 м — редкая.
- **Вода**: набережные без ограждений и коллизии кромки, нельзя плавать (сейчас вода = смерть).
- **Освещение пешехода**: ночью нет света из окон подъездов/витрин на тротуар, нет фонаря у входов.
- **Навигация ИИ пешком**: нет навмеша — полиция и пешеходы идут по прямой/графу тротуаров, через дворы и здания не ищут путь.
- **Звуки шагов по покрытиям** — события есть (`footstep.surface`), библиотеки звуков нет.
