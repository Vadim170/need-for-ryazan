# Процедурные машины (параметрический генератор)

Код: `game/src/vehicles/procedural/` — **один** генератор для трафика (`src/traffic/models.ts` → `render.ts`), припаркованных машин
(`src/world/parked-gltf.ts`) и витрины `?carshow=1`. glTF-модели (`public/assets/vehicles/vehicles.json`, сейчас `lada_largus`, `uaz452`)
по-прежнему приоритетнее: вид, для которого есть glTF с ролью `traffic`, целиком рисует `GltfTrafficLayer` (контракт не менялся).

## Устройство
| Файл | Что |
|---|---|
| `mesh.ts` | `MeshBuilder` (индексная сетка: position/normal/color/aPart/uv), `loft` (лофт колец-сечений со сглаженными нормалями и цветом по ячейкам), `patch`, `box`, `tube`, `pchip`; `PART` |
| `body.ts` | `BodySpec` и `buildBody(spec, lod)`: нижняя часть кузова + остекление — **лофт колец вдоль длины** (скруглённый план носа/кормы, обжим плеча, нижняя чёрная кромка/бампер), зоны остекления (лобовое/боковые/стойки A-B-C/заднее), колёсные арки (тёмный диск на стенке + закрылок), фары/фонари/поворотники/решётка/противотуманки как заплатки по поверхности торца, номера (белые с триколором и «RUS», цифры-блоки), зеркала, швы дверей, ручки, рейлинги, брызговики (Лады), хромированные бамперы (2107), грязевой градиент по низу лака |
| `wheels.ts` | единичное колесо (радиус 1, ширина 1 вдоль X): шина с боковиной и протектором, бочка, тормозной щит, диск стиля `steel`/`steelcap`/`alloy5`/`alloy10`/`turbine`/`bus`; LOD 1 (7 граней) и 2 (12 граней, парковка) |
| `presets.ts` | пресеты с реальными габаритами (L×W×H, база, свес, радиус колеса) на шаблонах силуэтов `sedan/liftback/hatch/wagon/suv`, ГАЗель (маршрутка/фургон/скорая), автобусы (ПАЗ-3205 с капотом, ЛиАЗ-5292, Тролза-5265, ЗиУ-682 со штангами), ливреи (такси: жёлтый, «шашечки» на дверях и знак; ДПС: синяя полоса + красная линия + мигалка; скорая: красная полоса, бар) |
| `index.ts` | `allVariants()` — генерация один раз за сессию (кеш): LOD0 кузов (без колёс), LOD1 (колёса вмурованы), колёса, габариты, веса |
| `carshow.ts` | отладочная витрина |

Лофт: сечение — ломаная «слева → через верх → вправо» из 9 точек (нижняя часть: днище, кромка, юбка, стенка, плечо, капот/багажник)
или 6 (остекление: пояс, стекло, рейка, угол крыши, крыша). Профили — PCHIP по ломаным `lowTop` (капот/пояс/багажник) и `roof`;
станции густо у скруглений носа/кормы, по зонам и контрольным точкам. Роли ячеек (стекло/лак/чёрное) задаются по id сегмента и зоне,
вершины дублируются по ячейкам, нормали — сглаженные по сетке (острые рёбра только на границах деталей).

## Пресеты и состав (Рязань)
Оценка по панорамам Яндекса (`data/raw/panoramas`, ~25 кадров вручную): машины на кадрах мелкие, но видно — преобладают Лада Гранта/Веста/
Приора/2114/Калина, Солярис/Рио/Поло/Логан, кроссоверы (Крета, Дастер), Нива, Ларгус, встречаются 2107; цвета — белый/серебро/серый/чёрный
(~70%), остальное синий/красный/вишня/зелёный/бежевый; грузовики, белые ГАЗели-маршрутки. Веса трафика (внутри вида) и парковки — поле
`weight`/`parkedWeight` в `presets.ts`; доли видов — `CAR_MIX` в `traffic/sim.ts` (седан 33, хэтч 20, универсал 12, кроссовер 20, такси 5, ДПС 2, ГАЗель 8),
палитра — `PALETTE` (sim.ts) и `CAR_PALETTE` (props.ts, парковка).

Вариант выбирается хэшем `id` машины (`render.ts: pick`). Реальная кинематика симуляции — по эталону вида (первый вариант, `VehicleModel`);
у каждого варианта задняя ось сдвинута по Z (`dz`) на ось эталона, свой радиус/ширина/база колёс — только в рендере.

## Табличка маршрута
`PART.board` (9): заплатка с UV на лобовом стекле/над лобовым/на правом борту; ячейка атласа 128×32 (`routeBoards` в `traffic/models.ts`,
canvas 8×8 ячеек, рисуется лениво) выбирается пер-инстансным атрибутом `aRoute`. Номер — реальный `ref` маршрута OSM
(`net.routes[v.route].ref`; ЛиАЗ/троллейбус — янтарное табло, маршрутка — бумажная табличка). Маршрутки вне маршрутов берут случайный `ref` из реальных
`share_taxi` (33, 41, 46, 47, 49, 50, 53, 58, 62, 65, 66, 68, 71, 73, 88, 95).

## Рендер (трафик и парковка): THREE.BatchedMesh
- Трафик (`traffic/render.ts`): **два BatchedMesh** — «ближний» (LOD0 всех вариантов + колёса по стилям диска, отбрасывает тени, `nearLod` = 55 м) и «дальний»
  (LOD1 ≈ 600 треугольников, колёса вмурованы; геометрия на группу дальнего LOD — вид, масштаб по габариту варианта). Экземпляры — слоты геометрии
  (`vehicles/procedural/batch.ts: SlotBatch`: слоты создаются по требованию, на кадре заполняются [0,n), остальные скрываются; отсечение и сортировка — наши,
  `perObjectFrustumCulled/sortObjects` выключены). Цвет — `setColorAt` (лак красится в шейдере по `getBatchingColor`); пер-экземплярные фары/стоп/поворотник/маячок и
  ячейка таблички маршрута — в float-DataTexture по instanceId (`InstanceData`, `vehicleMaterial(env, lampTex)`; ключ программы `nfr-traffic-veh-b`).
  glTF-слой (`GltfTrafficLayer`) остаётся на InstancedMesh.
- Парковка (`world/parked-batch.ts`): **два BatchedMesh на все процедурные виды** (`ParkedBatch`): LOD0 до 40 м (с тенью), LOD1 до 190 м, дальше до 420 м — «коробка»
  (≈ 50 треугольников, `boxImpostor`). `Props.addParkedCarModels` принимает готовые пулы (`PoolLike`: count/begin/addBlock/addOne/commit) вместо InstancedMesh-пулов;
  glTF-машины парковки (Largus, УАЗ-452: у каждой свой атлас-текстура) остаются на обычных пулах.
- Замеры (двор `?spawn=2`, один и тот же вид, полный кадр с тенями): раньше 50 InstancedMesh-пулов процедурных машин (≈ 50–75 draw call'ов), сейчас +5 draw call'ов
  и ≈ 0.36M треугольников (LOD0 до 40 м + LOD1/коробки). Трафик: раньше 17 InstancedMesh (≈ 82k треугольников при 68 машинах), сейчас 2 BatchedMesh.
- Грязь: градиент по низу лака (вершинный цвет, ×цвет инстанса) + ~24% машин сдвигаются к серо-коричневому.

## Для других модулей
- Лак: `PART.paint` (aPart = 0), нормаль «крыша вверх» — верхние кольца лофта (`greenRing`, id 3–5; нормаль +Y) — для снежных шапок.
- Материал — `vehicleMaterial` (traffic/models.ts), `customProgramCacheKey` `nfr-traffic-veh`; добавлены `PART.board` (табличка, uniform `uBoards`) и
  `PART.chrome` (хром: rough 0.22, metal 0.85), атрибут `aRoute`.
- Цвет вариантов: `fixedPaint` (такси/ДПС/скорая); кузов красится `instanceColor`.

## Витрина `?carshow=1`
`?carshow=1&world=test&traffic=0&people=0&time=12:00&debug=0`, затем в консоли:
`__game.carshow.view({ids?, from?, to?, mode: 'side'|'q34'|'rear34'|'front'|'top', lod: 0|1, lamps: 0|1, brake, ind, dist, fov})`; `__game.carshow.stats()` — треугольники LOD0/LOD1 всех вариантов.
(скрытая вкладка: `__game.frame(0.016, t)` несколько раз после `view`).

## Ограничения / дальше
- Арки — накладки на стенке, а не вырезы; в вариантах с кузовом ближе к земле колесо чуть утоплено.
- Формы шаблонные: узнаются класс и ключевые черты (капот/багажник/хэтч/универсал/пикап-подобный Патриот), не точные копии; морды — по параметрам фар/решётки.
- ЛиАЗ/троллейбус 4 колеса (у реальных 3 оси); двери только обозначены швами/тёмными створками.
- Реальные glTF из Sketchfab (очередь `assets/catalog/vehicles.json`) — ждут токен `~/.config/sketchfab/token` (на момент написания файла нет).
