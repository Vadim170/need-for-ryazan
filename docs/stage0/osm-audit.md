## 7. Вывод

### Достаточно хорошо
- **Геометрия улиц и зданий**: 8364 здания, 77% с адресом, плотная сеть дорог (ок. 264 км авто-дорог без service, ещё 351 км service). Контуры зданий годятся для экструзии.
- **Классы и поверхность**: surface у primary/secondary ~100%, oneway у primary 93%, у secondary 72%.
- **lanes на главных магистралях**: Солотчинское шоссе 99.8%, Соборная 98%, Есенина 92%, Циолковского 88%, Свободы 88%, Ленина 83%, Первомайский пр. 79%, primary в целом 85%. Этого достаточно для базовой разметки полос основных осей.
- **Светофоры и переходы**: 139 светофоров-узлов, 602 перехода (197 со светофором), 229 bus_stop, 215 stop_position.
- **Общественный транспорт**: 13 троллейбусных и 16+ автобусных маршрутов с остановками-членами; хорошая основа для ТС по маршрутам.
- **Ориентиры**: кремль (с соборами, колокольней, дворцом Олега), цирк, театры, Телебашня, памятники, Лесопарк, ЦПКиО, пост ДПС; ~270 именованных кандидатов.
- **Вода/зелень**: Ока, Трубеж, Лыбедь, карьеры, Лесопарк 145 га, ЦПКиО 53 га, леса.

### Чего не хватает
- **Высота зданий**: building:levels только у 21%, height у 0.1% (6 зданий), roof:shape у 2.7%, building:part всего 67. Высоты придётся оценивать эвристикой (типология, ширина, этажность по аналогам), для hero-зданий вручную.
- **turn:lanes**: лишь 2.4% длины дорог (primary 2.7%, secondary 16.5%); на Первомайском, Соборной, Ленина, Свободы, Московском ш. нет совсем; Есенина/Циолковского ~21%; Солотчинское 5%. lanes:forward/backward почти нет (2%) — для двусторонних дорог число полос по направлениям придётся выводить из lanes/2.
- **width**: 1.4%, значит ширину полосы/проезжей части брать по умолчанию (3.25-3.5 м) и по снимкам.
- **maxspeed**: 21% длины (primary 56%, tertiary 14%, residential 11%): нужна таблица значений по умолчанию РФ (60 в городе, 20 во дворах).
- **lit** ~27%, фонарей (street_lamp) 0 узлов: освещение генерировать процедурно.
- **traffic_sign**, give_way, stop: практически отсутствуют (1 stop): приоритет перекрёстков выводить из классов дорог и светофоров.
- **Деревья**: 141 узел natural=tree и 2 tree_row на весь bbox — деревья расставлять процедурно по parks/wood/landuse и вдоль улиц.
- **Лыбедский бульвар**, Магистральная, Подбельского, Октябрьская, Профсоюзная не найдены по имени (под другими названиями или без name): проверить вручную в JOSM. Высоковольтная — 0% lanes.
- Метаданные светофоров: traffic_signals=signal лишь на 14 из 139; направлений нет.
- Данные ТС: 39 отношений без остановок (обрубки), часть маршрутов — дубликаты направлений; маршрутки (share_taxi) в расчёт брать не стоит.

### Что требует ручной правки (JOSM)
1. **turn:lanes и lanes:forward/backward** на основных осях игры (Первомайский, Соборная, Ленина, Свободы, Есенина, Циолковского, Солотчинское, Касимовское, Московское, Грибоедова, Вокзальная, Дзержинского, Высоковольтная, Куйбышевское): ок. 30-35 км, 100-130 перекрёстков с подходами.
2. **Проверка топологии перекрёстков со светофорами** (139 + переходы): направления, фазы, stop line, привязка crossing к переходу.
3. **hero-здания** (кремль, соборы, цирк, театры, ДПС, ТЦ «Круиз», Телебашня и т.д.): building:levels/height/roof:shape, building:part для сложных форм: 30-50 объектов.
4. **Лыбедский бульвар и разрывы**: поиск/дорисовка недостающих сегментов, мосты через Оку/Трубеж/Лыбедь (проверить layer/bridge: 30 мостов, 22 тоннеля).
5. maxspeed на магистралях (по знакам; ок. 50-60 км/ч) — можно батчем по классу.

### Грубая оценка ручной работы
- Автоматизируемо (скриптом по умолчаниям): maxspeed, width, этажность остальных зданий, деревья, фонари, освещение, приоритеты.
- Ручное: turn:lanes на основных осях — ~25-40 ч; проверка перекрёстков/светофоров — ~10-15 ч; hero-здания — ~10-15 ч; мосты/разрывы — ~5 ч. Итого порядка **50-75 ч** для полноценного «узнаваемого» качества, или **~20-25 ч** для минимума (только 4-5 главных осей и 20 hero-зданий).
- Оценка грубая: основана на числе объектов и ориентировочной скорости правки 3-5 перекрёстков/ч, не измерялась.

### Технические замечания
