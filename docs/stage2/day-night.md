# Смена дня и ночи (Этап 5)

Код: `game/src/render/` — `time-of-day.ts`, `day-night.ts`, `night-lights.ts`, `post.ts`, `day-night-gui.ts`.

## Время
- `GameClock` (`rc.dayNight.clock`): 1 игровые сутки = 24 реальных минуты (`?daymin=N` или GUI). Старт: `?time=HH:MM` (по умолч. 10:00), дата `?date=YYYY-MM-DD` (по умолч. сегодня; от неё зависят высота солнца и длина ночи). Часовой пояс UTC+3.
- Клавиши `[` и `]` — сдвиг на ∓1 час. Пауза и слайдер часа — в debug GUI, папка «day / night».
- Консоль: `__game.dayNight.clock.setHour(18.5)`, `.paused = true`; шаг кадра вручную — `__game.frame(dt,t)`.

## Астрономия
- Солнце: низкоточный алгоритм (Meeus), широта 54.636, долгота 39.750; положение → мировой вектор (x восток, −z север).
- Луна: основные члены эфемерид + фаза по элонгации (диск с фазой в шейдере). Звёзды: 3000 точек, вращаются со звёздным временем.

## Небо, свет, туман
- Небо — собственный шейдер: горизонт/зенит по палитре `STOPS` (ключевые кадры по высоте солнца), закатное свечение, диск солнца (HDR → bloom), слой облаков (`dayNight.cloudCover`).
- Цвет горизонта == цвет тумана, поэтому граница стриминга растворяется в небе. `fog.far ≤ 720 м` всегда (ночью/на закате 640–700).
- Одна DirectionalLight с тенями: солнце днём, луна ночью (интенсивность/направление смешиваются). Тени гаснут при солнце ниже ~9° (`shadow.intensity`). Полусферный свет и экспозиция — из палитры (ночью экспозиция выше).
- Отражения (PMREM неба) запекаются один раз при высоком солнце; ночью `envMapIntensity` материалов с этим envMap приглушается.

## Глобальные uniform-ы (для материалов)
`import { timeUniforms } from './render/time-of-day'` — объекты `{value}`, можно класть прямо в `shader.uniforms`:
`nightFactor` (0 день … 1 ночь; солнце +6°…−6°), `windowLit`, `sunDir`, `moonDir`, `skyColor` (= цвет тумана), `hour`.
Для world-материалов уже есть `cityUniforms` (`world/materials.ts`): `uNfrNight` (множитель свечения окон/плафонов, включается на закате) и `uNfrWin` (доля горящих окон по часу — `windowLitCurve`).
Хелпер `headlightsWanted(prev)` — включать фары по `nightFactor` с гистерезисом (0.4 вкл / 0.25 выкл).

## Ночное освещение
- Окна зданий: случайно по окну, тёплые/нейтральные/холодные, доля по часу (вечер ~60%, к 4 утра ~7%, утром снова растёт). Шейдер в `world/materials.ts` (маленькая правка: `uNfrWin`).
- Плафоны фонарей светятся (`props.ts`, `uNfrNight`). Пятна света на дороге — `NightLights`: один InstancedMesh аддитивных круглых декалей (до 256, фонари в радиусе 220 м, обновление при смещении >5 м). Нужен хук `Props.collectLamps()`.
- Фары игрока: 2 `SpotLight` без теней, интенсивность плавно нарастает; `car.lights.setHeadlights()` включает эмиссию фар/габаритов. Динамических PointLight нет.
- Bloom: `PostFX` (RenderPass → UnrealBloom (порог 1.0, только HDR-эмиссия) → OutputPass). `?bloom=0` или GUI. Сила днём 0.12, ночью 0.4. MSAA в буфере отключается при >2.5 Мпикс (retina 4K), иначе +16 мс.

## Для трафика и пешеходов
- `rc.dayNight.clock.onHourChanged((hour) => { traffic.setDensityFactor(trafficDensityCurve(hour)); people.setDensityFactor(pedestrianDensityCurve(hour)); })` — кривые экспортирует `time-of-day.ts` (пик 8–9 и 17–19, ночью 0.1). Модулей `src/traffic`, `src/people` на момент написания нет — подключение не сделано.
- Фары/стопы трафика: читать `timeUniforms.nightFactor.value` (или `headlightsWanted`) и включать эмиссию per-instance; bloom подхватит эмиссию >1.

## Производительность (retina 1920×1024 @DPR2, Chrome, кадр с gl-finish)
Без bloom ≈ 7.9 мс, с bloom ≈ 14 мс (ночь). Днём/ночью без bloom разницы нет.
