# Звук: двигатель «бархатный рёв», машина, город, погода, GTA-режим

Код: `game/src/audio/`. Ассеты: `game/public/assets/audio/` (≈15 МБ AAC). Пайплайн: `assets/scripts/audio/`.
Исходники записей: `assets/audio/sources/<категория>/<id>/` (превью freesound + `meta.json` с лицензией).
Тестовые рендеры: `assets/audio/test_renders/` (WAV + PNG-спектрограммы + `metrics.json`).

## Пресеты двигателя

`?engine=velvet|aggressive|stock` или debug-панель → «audio (N = mute)» → engine preset (переключается на лету).

| Пресет | Записи | Характер |
|---|---|---|
| **velvet** (по умолчанию) | 3.2 V6 VTEC со спортивным выхлопом, микрофон у выхлопа и «двигатель+выхлоп» (EvanBoyerman, CC BY 4.0): холостой, медленные разгоны в городе, полный газ, накат | Глубокий, гладкий V6-гул, не жужжит; на низах — мягкое «бу-бу», к верху — ровный рёв; хлопки на сбросе |
| **aggressive** | Оппозитник: WRX с 3" турбо-прямотоком (холостой с «булькающей» неравномерностью, перегазовки — для сброса) + GT86 с нагнетателем на стенде (разгоны 1750–7500) | Рокот оппозитника, турбо-свист и стравливание, частые прострелы |
| **stock** | MGB 1.8 (микрофон на бампере: холостой, город, сбросы) + Ford Escort 1.6 (разгон до отсечки) | «Обычная» рядная 4-ка, почти без хлопков — как сток Largus |

Тон пресета (EQ, сатурация, хлопки, турбо) — `ENGINE_PRESETS` в `src/audio/engine-audio.ts`.

## Как устроен двигатель

**Пайплайн** (`assets/scripts/audio/`, Python в `.venv`: librosa, numpy, scipy, soundfile, pyloudnorm):
1. `fs_search.py` / `fs_fetch.py sources.txt` — поиск и скачивание HQ-превью freesound без логина; лицензия проверяется на
   странице (CC BY-NC и Sampling+ отбрасываются).
2. `track_preset.py <preset>` — **отслеживание оборотов**: частота вспышек `f` (Гц, `rpm = f·120/цилиндров`) по гармоническому
   признаку (сумма отбелённого спектра на гармониках `k·f`) + Витерби вдоль ручной «направляющей» (`presets.py`: точки
   (t, f) по спектрограмме ±14 %). Картинки-проверки: `assets/audio/analysis/gtrack_<id>.png`.
3. `build_engine.py <preset>` — **нарезка лупов по бинам оборотов** (ниже 3000 — каждые 150–250 об/мин; выше — 300–500) для
   слоёв `idle` / `off` (сброс, накат) / `cruise` (частичный газ) / `on` (нагрузка):
   - участок записи вокруг нужных оборотов **выпрямляется по тону** (time-warp по фазе вспышек → идеально постоянная частота);
   - длина лупа — целое число рабочих циклов (2 оборота), 0.4–1.3 с (на низах длиннее — меньше «механической» периодичности),
     холостой — 3.2 с из 21 цикла (естественная неровность);
   - бесшовная склейка (хвост в начало, кроссфейд), поворот фазы — у всех лупов основная гармоника начинается с одной фазы
     (соседние бины складываются без гребёнки);
   - отбор: минимум «искажения» тона, затем проверка устойчивости тона (≤ 20–40 центов), иначе берётся следующий кандидат;
   - громкость каждого лупа выравнивается; всё в один спрайт `engine.m4a` (AAC 160k, с периодическими полями 0.1 с —
     защита от задержки кодека) + `manifest.json` (бины, частоты, исходники).
4. `analyze_render.py` — проверка рендеров: клиппинг, true peak, LUFS, щелчки (выбросы второй разности), точность
   слежения тона за оборотами (центы), спектрограмма с ожидаемой кривой.

**Рантайм** (`engine-worklet.ts`, AudioWorklet): **синхронный по циклам гранулярный синтез (TD-PSOLA)**. Общая фаза вспышек
растёт с текущей частотой; на каждой вспышке каждый активный бин выдаёт «зерно» — ту же по счёту вспышку из своего лупа
(окно Ханна ±период). Поэтому: тон точно следует оборотам, резонансы выхлопа не «уплывают» при подтяжке тона, соседние бины
и слои смешиваются когерентно, неравномерность цилиндров из записи сохраняется. Между бинами — кроссфейд по log(f), между
слоями off → cruise → on — по «эффективной нагрузке» (педаль + момент). Если в слое нет записи на этих оборотах, его вес
отдаётся соседнему слою (overrun на высоких оборотах = on-слой тише и глуше).

`engine-audio.ts` (основной поток, всё планируется на время контекста — поэтому тот же код рендерится офлайн):
- обороты для звука: ограничение скорости изменения + сглаживание (физика может прыгать при трогании/переключениях),
  `rpmMap` пресета (обороты игры → обороты записи: холостой 900 → 780 у V6);
- переключение: срез на 0.2 с, щелчок КПП; понижение — перегазовка; отсечка — «дребезг» 12 Гц;
- хлопки на сбросе газа на высоких оборотах (случайные вспышки в выхлопе внутри worklet + записанные очереди anti-lag);
- впуск (шумовые импульсы на каждую вспышку, растут с газом), турбо (свист, стравливание), вой задней передачи;
- «бархат»: low-shelf +4.5 дБ @140 Гц, вырез 2.6 кГц, мягкая асимметричная сатурация, ФНЧ, открывающийся с нагрузкой;
- **нитро**: «пшш» баллона при включении, поток воздуха + низкий гул (две записи), растут с газом и плавно гаснут,
  «тссс» продувки при отпускании; двигатель громче (+2.5 дБ), ярче и на 3.5 % выше.

## Низкие обороты (по жалобе) — что сделано

- Плотные бины 150–250 об/мин ниже 3000, длинные лупы на низах; холостой — 3-секундный луп из реальной записи.
- Слой `cruise` (частичный газ на 1400–2400) из городской езды — «бу-бу» на малом газе; переход холостой ↔ трогание —
  PSOLA из холостого лупа (без «бурундучьего» эффекта).
- **Физика: найдено и исправлено** — автомат переключался только на 6300 об/мин (`shiftUpRpm`) независимо от газа, поэтому
  в городе на 20–30 км/ч машина ехала на 1-й передаче на 2500–3500 об/мин и при сбросе падала обратно. Теперь точки
  переключения зависят от сглаженной педали (`src/vehicle/vehicle.ts`, новые параметры `shiftUpEcoRpm` 2300 /
  `shiftDownEcoRpm` 1250 в `config.ts` и в debug-панели): малый газ → ранние повышения, полный газ (удержанный) →
  6300 / кикдаун 2600; решения по оборотам колёс, с гистерезисом (не «охотится»), короткое нажатие W не даёт кикдауна.
- Замечено, не трогал: на 1-й передаче при любом нажатии газа обороты сразу прыгают к 3600 (`launchRpm` — проскальзывание
  «сцепления» до этой скорости колёс). Звук это сглаживает (ограничение скорости роста), но при игре W-«постукиванием»
  на 5–15 км/ч рёв на каждом нажатии остаётся. Если мешает — уменьшать `launchRpm` с ростом скорости (влияет на разгон).

## Треск на долгом разгоне с нитро — причина и исправление

- **Причина (физика):** при зажатом Shift после опустошения баллона нитро включалось/выключалось почти каждый кадр
  (расход 0.25/с против пополнения 0.08/с вокруг порога 0.02) — **556 переключений за 23 с (~24 Гц)**. Каждое включение
  запускало звук «пшш» баллона и дёргало тяговое усилие, тон и громкость двигателя → непрерывный «треск».
  Исправлено в `vehicle.ts`: пустой баллон блокирует нитро, пока не отпущена клавиша (или не набралось 30 %);
  теперь при зажатой клавише ~10 переключений за 25 с (короткие повторные «впрыски»).
- **Звук:** состояние нитро сглажено (переключение в звуке — не чаще чем через 0.2 с, «пшш» — только после ≥0.6 с паузы);
  отсечка оборотов переделана с «пулемёта» 12 Гц (обрыв нагрузки + хлопки) на мягкое ~7 Гц покачивание оборотов без хлопков
  (лёгкое бульканье только у пресета aggressive); worklet: список активных гранул, статистика (пик гранул / потери),
  128 слотов — в живом тесте пик 21 гранула, потерь 0.
- **Уровни:** ветер и шум дороги на скоростях > 180 км/ч больше не растут квадратично; шина игрока −1.4 дБ; лимитер
  −6 дБ / 20:1 / 0.2 с + мягкий клиппер. Проверено вживую в Chrome (пост ДПС, Солотчинское шоссе, трафик, город,
  нитро зажато 20 с): пик на выходе 0.69, лимитер почти не работает (−0.2 дБ), перегрузок 0. Офлайн
  `velvet_nitro_long.wav` (газ + нитро 25 с до 228 км/ч на 6-й): клиппинга и разрывов нет, −12 LUFS. На отсечку в 6-й
  машина с нитро не выходит (упирается в сопротивление воздуха на ~6300 об/мин) — физику передач не трогал.
  Отсечку отдельно можно послушать в `velvet_limiter.wav` / `aggressive_limiter.wav`.

## Машина и окружение

- `vehicle-sfx.ts`: визг шин (по проскальзыванию), занос на ручнике, шум дороги и ветра (по скорости), удары по импульсу
  (пластик / металл / авария со стеклом), удары подвески, гудок (H), дождь по кузову, мокрая дорога / каша, снег под колёсами.
- `environment.ts`: свёрточная реверберация — 3 процедурных IR (поле 0.45 с, улица-«каньон» 1.2 с с ранними отражениями,
  тоннель/мост 2.2 с) + отражение от фасадов с задержкой 2·d/c. Зонд (`game-audio.ts`, 5 Гц): 8 горизонтальных лучей на 45 м
  к зданиям + луч вверх (мост/тоннель). Неактивные свёртки отключаются (экономия CPU).

## Город (`ambience.ts`, `city-zones.ts`)

Карта звуковых зон `public/assets/audio/zones/` строится из OSM: `assets/scripts/audio/build_audio_zones.py` (сетка 25 м,
каналы: трафик по классу дорог, зелень, промзоны, толпа — пешеходные улицы/магазины/остановки, дворы, детские площадки,
вода; точки церквей и остановок; пропсы мира: детские площадки, остановки, контейнерные площадки). Слои (лупы) звучат по
зоне вокруг слушателя, времени суток, плотности трафика/пешеходов, погоде и сезону:
городской гул, дальний трафик (по классу дорог рядом), гул толпы и шаги (Почтовая, Театральная, остановки, люди рядом),
птицы днём и вороны (парки, лесопарк), ветер в деревьях, дети на площадках днём, промгул и стройка (по будням днём), рассвет,
ночная тишина, дождь. События: лай собак во дворах, автосигнализации и сирены вдали (чаще ночью), колокола у церквей
(в начале часа 8–20 и изредка), гром. Позиционно с Допплером: моторы ближайших 6 машин трафика (лупы банка `stock`), автобусы
(+ пневмотормоза при остановке у остановки), троллейбус (+ вой тягового двигателя), грохот поезда и гудки (события `rail`).

## Погода, сезон, GTA

- `audio.setWeather({ rain, snow, wind, storm })` (0..1, вызывает `src/render/weather-system.ts`), `audio.thunder(delay, сила)`
  (молния), `audio.setSeason('summer' | 'winter')` — зимой снег/каша под колёсами, нет певчих птиц, меньше детей
  (**пока никто не вызывает**: погодной системе стоит дергать его при смене сезона; до этого — галочка winter в debug-панели).
  Снегопад приглушает город (ФНЧ на слоях). В debug-панели есть «weather test».
- GTA-режим (`gta-audio.ts`, события `src/combat/events.ts`): выстрелы ПМ / АКС-74У / дробовика с задержкой по расстоянию,
  поглощением верхов вдали и **эхом между домами** (отражение 2·d/c + «раскат» в каньоне), попадания (рикошет, металл, стекло,
  тело), удары, шаги по покрытию (асфальт/трава/снег), прыжок/приземление, двери, взрывы, перезарядка/щелчок/смена оружия,
  подбор, крики, звёзды розыска, wasted/busted; сирены полиции — позиционные лупы с Допплером (`police.sirens()`).
  Пешком брошенная машина звучит из своей точки в 3D.

## Управление и интеграция

- Звук стартует по первому жесту (клик/клавиша). **N** — mute (M — карта мира) (сохраняется), громкость/пресет/реверб — debug-панель.
- `main.ts`: `new GameAudio(physics)`, `audio.update(dt, {car, camera, hour, traffic, rail, …, onFoot, focus, sirens})`.
- Совместимость: `EngineAudio.setRpm/setThrottle/setLoad` сохранены.
- Форматы: AAC в `.m4a` — декодируют Chrome и Safari (macOS); лупы — с периодическими полями, так что задержка кодека
  не даёт щелчков.

## Как настраивать

- Тон/громкость пресета: `ENGINE_PRESETS` (`engine-audio.ts`): `shelfDb` (бархат/низ), `midDb`, `drive` (сатурация),
  `lp*` (яркость под нагрузкой), `offLoadDb` (громкость сброса), `crackle` (хлопки), `turbo`, `gainDb`.
- Соответствие оборотов: `rpmMap` в `presets.py` (пересобрать `build_engine.py`).
