# Здания v2: архетипы, этажность, крыши, фасады (stage 2)

Цель — вместо серых коробок город, узнаваемый как Рязань: хрущёвки, девятиэтажки, сталинки и купеческие дома в центре, частный сектор с вальмовыми крышами, гаражи, церкви. Всё процедурно, без ручного моделирования (кроме hero-объектов, которых пока нет).

Код:
- `pipeline/world/ortho_buildings.py` — анализ ортофото Яндекса → `data/processed/building_ortho.json` (цвет и тип крыши, длина тени). Запуск: `cd pipeline && uv run python -m world.ortho_buildings` (~70 с).
- `pipeline/world/archetypes.py` — классификация, этажность, крыша, цвет.
- `pipeline/world/building_geom.py` — геометрия (стены, крыши, карнизы, короба на крыше, купола, балконы).
- `pipeline/world/city_buildings.py` — сборка по тайлам; вызывается из `build_world.py` (флаг `BUILDINGS_V2`, False — старая экструзия).
- `game/src/world/building-material.ts` — шейдер фасадов и подготовка геометрии; `game/src/world/balconies.ts` — инстансы балконов. Хуки: одна строка в `materials.ts` (материал зданий), две в `city-world.ts` (подготовка геометрии, нода `balconies`).
- Контракт — `docs/world-format.md`, раздел «Здания v2». Отчёт сборки — `<work>/buildings_report.json` (`data/processed/sumo/` для основной сборки).
- Контрольные картинки — `data/processed/buildings_check/` (карта архетипов и скриншоты из игры).

## Источники данных и покрытие

Порядок для этажности: явная `height` OSM → реестр ЖКХ (`building_registry.json`, агент реестра) → `building:levels` OSM → панорамы (`levels_est` в `building_facades.json`) → тень на ортофото → догадка по архетипу и соседям.

Итог основной сборки (8331 здание, 8482 объёма вместе с `building:part`; реестр — полный, 1717 записей):

| Источник этажности | Зданий | % |
|---|---|---|
| OSM `height` | 11 | 0.1 |
| Реестр ЖКХ | 1710 | 20.5 |
| OSM `building:levels` | 1016 | 12.2 |
| Панорамы (`levels_est`) | 0 | 0 (агент фасадов пока не выдаёт этажность) |
| Тень на ортофото (+ форма и соседи) | 1348 | 16.2 |
| Догадка по архетипу (форма + соседи с известной этажностью) | 4246 | 51.0 |

Догадка — это в основном мелочь: сараи, гаражи, частные дома (там 1–2 этажа). Реестр совпадает с OSM в 90 % случаев точно и в 97 % — с точностью ±1 этаж (docs/stage2/registry.md). Из реестра используются также `wall_material` (кирпич → brick5 и кирпичная палитра, панель/блок → panel5, монолит → modern, дерево → деревянный дом), `roof_type` и `roof_material` (плоская/скатная/двускатная/вальмовая; рулонная/мягкая → плоская, шифер/металл → скатная; у шифера — серый цвет, у оцинковки — светлый) и `year` (эпоха архетипа).

Другие входы: цвет фасада с панорам есть у 1168 зданий, применён к 629 (уверенность ≥ 0.35); ещё 8 цветов из `building:colour` OSM, остальные из палитры архетипа с разбросом. Цвет крыши с ортофото — медиана по крыше, **привязанная к палитре кровель** (зелёный, красно-коричневый, синий крашеный металл, оцинковка, шифер; у плоских — оттенки битума). Получается один чистый цвет на крышу, без пятен. По контрасту скатов уверенно определились 3846 скатных и 1493 плоских крыши, длину тени удалось измерить у 3392 зданий.

### Оценка этажности (kNN)
Признаки: площадь, ширина и вытянутость повёрнутого прямоугольника, прямоугольность, положение (масштаб 350 м, чтобы микрорайоны «наследовали» этажность соседей), грубый класс, а также длина тени, если она есть. Ответ — взвешенная медиана 7 ближайших среди 2675 зданий с известной этажностью (OSM и реестр). Проверка leave-one-out на зданиях с измеренной тенью:

| | без тени | с тенью |
|---|---|---|
| MAE, все | 1.38 эт. | 1.11 эт. |
| MAE, многоквартирные | 1.51 эт. | 1.19 эт. (76 % с ошибкой ≤ 1 этажа) |

После оценки этажность «прилипает» к типовой: у хрущёвок 4 и 6 этажей становятся 5, у девятиэтажек 8 и 11 этажей — 9.

### Тень на ортофото
Яндекс снимал почти в надир, тени короткие, а крыши немного «завалены», поэтому длину тени в метры напрямую не переводим, используем её только как признак kNN. От стен на теневой стороне идут лучи вдоль азимута тени, чужие футпринты из выборки исключаются. По лучам строится профиль средней относительной яркости, и длина тени — расстояние, на котором профиль возвращается к яркости земли. Отдельные лучи слишком шумят из-за машин и крон, профиль устойчивее. Азимут подбирается перебором 320…10° по максимуму корреляции «длина тени ↔ этажность»: получилось 350°, корреляция 0.6 (0.69 на зданиях от 4 этажей).

### Тип крыши по ортофото
Для почти прямоугольных футпринтов шириной до 26 м сравниваем яркость двух половин вдоль длинной оси: скаты по разные стороны конька освещены по-разному. Метрика — контраст медиан, отнесённый к разбросу внутри половин. Проверка по 226 зданиям с `roof:shape` в OSM: у плоских медиана контраста 0.14, у вальмовых 0.58, у двускатных 0.59. Пороги: от 0.5 — скатная, до 0.22 — плоская, между ними — как принято для архетипа. Вальму от двускатной по ортофото надёжно не отличить, тут решают архетип и прямоугольность. `roof:shape` в OSM и тип крыши из реестра важнее ортофото.

## Геометрия (пайплайн)
- **Стены** — по одному квадрату на ребро футпринта. UV в метрах от начала стены, поэтому окна центрируются на каждой стене и не «переламываются» на углах. Стены вплотную к соседнему зданию помечаются глухими (брандмауэры в центре). Витрины 1-го этажа ставятся **только на участках стен, где слой улицы (`streetlife.py`) поставил запись `storefronts`**: стена режется на участки, сетка окон при этом не сбивается. Поэтому здания v2 строятся в `build_world.py` после streetlife. Без записи первый этаж — обычные квартирные окна, в том числе со стороны двора, проездов и парковок. Исключение — архетип commercial (ТЦ, магазины): там витрины по всему первому этажу.
- **Плоские крыши** — парапет: наружная стена поднята, внутренняя грань и крышка. На кровле: машинные отделения лифтов (9+ этажей, по секции), выходы на кровлю и вентшахты (5 этажей), короба вентиляции на ТЦ и складах.
- **Скатные** — «прямой скелет» поэтапным митровым смещением контура до событий рёбер (при расщеплении контур режется), со свесом 0.2–0.4 м и подшивкой. Для дворовых (с дырами) — пояс скатов и плоский верх. Мансарда — крутой нижний ярус и пологий верх. Двускатная — по повёрнутому прямоугольнику, с фронтонами; только у прямоугольных футпринтов. Подъём ограничен: у сталинок и купеческих 4 м, у частных домов 6 м.
- **Карнизы** у сталинок и купеческих — выступающий пояс 0.35 м.
- **Купола** — тела вращения: луковица, полусфера, барабан, крест. Берутся из `building:part` OSM (кремль: Успенский собор, колокольня и другие). У 36 церквей без частей ставятся процедурные купола: барабан с луковицей, 4 малые главы у крупных храмов, колокольня с шатром у вытянутых. Hero-моделей колокольни и Богоявленской церкви в `assets` нет (в каталоге они только как ссылки на Sketchfab), поэтому всё процедурное. Когда модели появятся, соответствующие OSM-объекты нужно будет пропускать.
- **Балконы** — стопки-инстансы в ноде `balconies` (формат в `world-format.md`). Правила по сериям: 1-464 — каждая 3-я колонка, одна длинная сторона, 55 % застеклены жильцами; 1-447 — каждая 4-я колонка; II-49 — парные лоджии на одной стороне и редкие кухонные балконы на другой; точечные — угловые лоджии; сталинки — центральная ось фасада к улице, без верхнего этажа; современные — застеклённые через колонку на всех сторонах. Козырьки подъездов делает агент улиц, здесь их нет.
- Итого: **~497 тыс. треугольников на весь город** (в среднем ~570 на тайл) и 132.5 тыс. балконов.

## Шейдер фасадов (игра)
Один материал на все здания тайла, 1 draw call. Ветвление по `_ARCH`:
- сетки окон: шаг, ширина, высота и подоконник по архетипу; у купеческих и церквей арочный верх окон;
- материал стены: швы панелей (по этажам и по шагу окна), кирпич (раскладка со смещением рядов, затухает с расстоянием), брёвна у деревянных изб, штукатурка с пятнами; тёмный цоколь;
- декор: у сталинок руст 1-го этажа, межэтажный пояс, пилястры, сандрики над окнами; у купеческих межэтажные пояса; у изб наличники (белые, синие, зелёные); у современных акцентные вертикали и тёмный 1-й этаж;
- окна: псевдо-глубина откоса (стекло сдвигается по направлению взгляда в касательном базисе стены, по краю виден откос), рамы ПВХ или старые деревянные, переплёты, шторы и тюль, кондиционеры (~10 % окон), отражение неба по Френелю;
- витрины 1-го этажа (часть 1), ворота гаражей (разноцветный профлист с ржавчиной), ленточное остекление у промзданий;
- крыши: один цвет на крышу из пайплайна плюс только мелкая фактура (битум с редкими заплатами; шифер — волна; металл — фальцы). Ржавчина — только у части частных домов, гаражей и сараев. Купола золотые или крашеные.
- **Ночь**: светятся окна. Яркость = `cityUniforms.uNfrNight` × доля горящих `uNfrWin`, обе величины пишет `render/day-night.ts`. Свет тёплый, нейтральный или холодный; у штор тусклее; верх окна ярче (светильник под потолком). Витрины светятся почти все. У застеклённых балконов часть тоже светится.
- Тайлы старого формата (`building_<type>`, без `_ARCH`) рисуются в наследном режиме.

## Проверка
Скриншоты сделаны в игре на `data/processed/world_test` (`data/processed/buildings_check/`; после правок витрин и цветов крыш — `kremlin_v2.jpg`, `yard_v2.jpg`): Кремль и Соборная, Театральная, Первомайский, микрорайон 9-этажек (днём и ночью), частный сектор, улица в центре. С панорамами Яндекса сверено выборочно: вальмовые крыши из ржавого металла у частных домов, бежевые и серые панельки, силикатный кирпич, цветные верхи новостроек. ## Известные ограничения
- Ошибки разметки OSM: например, `building=retail` на Соборной, 20А охватывает целый квартал вместе с площадью (10.5 тыс. м²). Камера, оказавшаяся внутри такого «здания», видит изнутри только парапет.
- Этажность без реестра и OSM — оценка (MAE ~1.3 этажа у многоквартирных). Сталинки на периферии определяются эвристикой: 2–4 этажа, широкий или сложный футпринт.
- Фасад рисуется одинаково по всему зданию, кроме витрин и глухих стен; особенности отдельных секций не учитываются. У частей (`building:part`) цвет панорам не используется.
- Колонки окон не согласованы с подъездами агента улиц: дверь может прийтись на окно 1-го этажа. Пол 1-го этажа поднят на цоколь (0.5–1.2 м), а крыльцо у агента улиц высотой 0.45 м.
- Длина тени — только признак kNN, не измерение высоты: из-за завала крыш и мозаики разных дат съёмки прямой пересчёт ненадёжен.

## Склоны: ступенчатые секции и высокий цоколь
Раньше пол 1-го этажа ставился по самой низкой точке рельефа под футпринтом, и на склонах ~1200 из ~4500 подъездов оказывались ниже земли. Теперь `city_buildings.ground_plan(ss, grid, H, base_height)` строит план уровней здания:
- **длинные дома с плоской крышей на склоне** (длина ≥ 30 м, ≥ 2 секций, перепад ≥ 0.6 м) режутся поперёк длинной оси на `sections` секций. У каждой секции пол = максимум рельефа по её контуру + цоколь, своя плоская крыша; на стыке получается видимая ступенька фасада, как у советских домов. Стены на стыке секций глухие;
- **остальные** — один объём, пол = максимум рельефа по контуру + цоколь. С низовой стороны стена уходит до земли, открывая высокий цоколь с окнами подвала, а при цоколе выше 1.6 м — ещё ряд окон цокольного этажа;
- подъём ограничен 6 м (`MAX_LIFT`); здания с `building:part` и церкви строятся по-старому;
- API: `ground_plan(...).floor_at(x, y)` — пол 1-го этажа ближайшей секции (мир пайплайна), `.base_at(x, y)`, `.floor`, `.sections`. `ground_level()` не изменился: это минимум рельефа, низ стен.

Итог: секциями построено 1442 дома, пол поднят у 5307 зданий. При полах из `floor_at` подъездов ниже земли нет — 0 из 4506 (раньше 1194; посчитано по `entrances` сборки).

## Цвета с панорам (итоговый файл агента фасадов)
Правила из docs/stage1/facades.md:
- берём только цвета с уверенностью ≥ 0.5 (класс `dark_grey` — от 0.6);
- светлота L\* ×1.3;
- при уверенности < 0.7 цвет на 30 % смешивается с цветом из палитры архетипа;
- материал с панорам не перекрывает `wall_material` из реестра.

Цвет с панорам получили **1384 здания** (есть в файле у 3788).
