# Hero-модели ориентиров (stage 2)

Ориентиры, которые процедурный генератор зданий не передаёт: **Рязанский театр драмы** (Театральная пл., 7), **Рязанский цирк** (Лево-Лыбедская ул., 34), **памятник В. И. Ленину** на площади Ленина. Каждая модель построена процедурно в Blender (Python), запечена в текстуры и подключена через общий механизм. Через него же добавляются новые ориентиры: колокольня, соборы, Почтамт, вокзалы.

## Источники и замеры

Для каждого объекта: 24 панорамы Яндекса вокруг объекта (средний зум 3584 px, скачиваются только тайлы в сторону объекта), из них построены прямолинейные кадры. Плюс ортофото Яндекса 0.25 м с наложенными контурами OSM и сеткой 5 м.

- **Театр драмы** (OSM w96881608). Неоклассика: портик из 10 коринфских колонн во всю ширину, по одной колонне в глубину с каждой стороны, глубина портика — два пролёта. Треугольный фронтон с барельефом, жёлтые стены с белыми пилястрами, арочные окна, жёлтый фриз, гранитный стилобат с лестницами спереди и с боков. Надписи на фризе нет, поэтому её не ставили. Ширина 39 м по OSM и ортофото. Высоты получены лучами из поз панорам на плоскость колоннады: колонна около 16.3 м, верх карниза 20.6 м, вершина фронтона около 26.4 м. Положение определено триангуляцией углов портика по 5 панорамам (невязка ≤ 1.6 м): портик стоит **на 6 м юго-восточнее**, чем контур OSM. Контур снят по крыше, а крыша на ортофото завалена к северо-западу. Длина около 64 м: на ортофото крыша короче контура. Поэтому у театра `keepFootprint: false`, и препятствием служит футпринт модели, а не контур OSM.
- **Цирк** (OSM w101850040). Восьмигранник: по кровле R ≈ 31 м, вершины на 7° + k·45°. Купол Ø 45 м, барабан-фонарь Ø 14 м с красной надписью «ЦИРК». Первый этаж бежевый, над ним витражный пояс высотой ~6.4 м с цветными импостами и квадратами, сзади П-образный служебный корпус по контуру OSM, у входа навес на чёрных гранитных опорах со сменной афишей. Центр взят по контуру OSM (−33.8, −578.5): триангуляция барабана по 5 панорамам даёт (−33.2, −576.9), а центр на ортофото смещён на север завалом.
- **Памятник Ленину** (OSM n736442710). Красная гранитная платформа 18 × 8.7 м со ступенями на запад, постамент — усечённая пирамида, бронзовая фигура в пальто, правая рука указывает вперёд-вправо (на северо-запад), цветочницы. Триангуляция фигуры по 6 панорамам совпала с платформой на ортофото в пределах ~1 м. Пропорции по кадрам: фигура ≈ постамент по высоте, около 5.6 м. Фигура стилизованная: слеплена из примитивов, объединённых вокселями (Remesh), сглажена и прорежена.

## Модели

| id | LOD0, тр. | LOD1, тр. | glb LOD0 / LOD1 | материалы (draw calls) |
|---|---|---|---|---|
| drama_theatre | 41 056 | 11 377 | 1.1 МБ / 0.31 МБ | 4 |
| circus | 14 638 | 9 642 | 0.63 МБ / 0.31 МБ | 4 |
| lenin_monument | 18 318 | 2 706 | 0.39 МБ / 0.10 МБ | 4 |

Конвенция модели: glTF +Y вверх, перёд — локальная −Z (в Blender +Y), метры, начало координат — центр футпринта на уровне земли. Как устроена сборка (`lmlib.run`):
1. Геометрия копится в `Mesh` (коробки, тела вращения, призмы, протяжки профиля, текст, «лепка»). У материалов роли: `opaque`, `stone`, `glass`, `metal`, `bronze`.
2. Материалы процедурные (ноды Cycles в мировых координатах): штукатурка с потёками, гранит, фальцы кровли, швы облицовки, патина бронзы. Свечение задаётся параметрами: `emit` — окна и надписи, `wash` — подсветка прожекторами, затухает с высотой.
3. UV: Smart UV по объектам, плотность выравнивается между объектами с весами `uvk` (крыши 0.3–0.35), затем общая упаковка. Мелкие повторяющиеся детали (`palette=True`: наличники, капители, переплёты) своих островов не получают: все их грани смотрят в клетку-палитру своего материала в нижней полосе атласа.
4. Запекание Cycles (Metal GPU): albedo × AO и emissive, 2048 для LOD0 и 1024 для LOD1. Процедурные материалы заменяются итоговыми по ролям (`lm_*`), объект один на LOD.
5. Коллайдеры: дочерние кубы ноды `collider` (`extras.collider = 1`). Метаданные (футпринты, пятна света) лежат в `extras.nfr_landmark` и в `build.json`.
6. `pack_landmark.sh`: dedup, prune, текстуры в WebP, сжатие meshopt.

  "loadRadius": 1100, "lod1Distance": 260,

## Пайплайн (`pipeline/world/landmarks.py`)

- `LM.apply(osm)` вызывается сразу после правок контуров (`building_overrides`). Здания из `suppress.buildings` получают тег `nfr:hero=<id>`: `archetypes.classify` их пропускает, и процедурного здания с коллайдером нет. При `keepFootprint` (по умолчанию true) контур остаётся препятствием для дворов, площадок, пропсов, деревьев, тротуаров и пешеходного графа. При `false` контур выключается (`building=no`). `building:part` внутри заменённого контура гасятся. Каждый футпринт модели добавляется синтетическим путём `building=yes, nfr:hero` — это тоже только препятствие.
- `LM.clear_props(yard.ctx, sl)` вызывается после улицы, до проходов в оградах. Убирает инстансы, сегменты, витрины и подъезды внутри футпринтов (+0.4 м), например скульптуру, которую пешеходная зона ставит по OSM-узлу памятника.
- Проверка: `build_world.py --out data/processed/world_test_hero` и основная сборка: `hero-модели: 3, заменено зданий OSM 2, футпринтов-препятствий 6`. В футпринтах ничего не осталось.

## Игра (`game/src/world/landmarks.ts`)

- Загрузка по расстоянию от машины. В `loadRadius` грузится LOD1, ближе `1.5 × lod1Distance` — LOD0. Переключение LOD идёт с гистерезисом, дальше `loadRadius + 200 м` модель выгружается.
- Высота модели берётся из heightmap по `ground.points`. Коллайдеры — кубоиды Rapier по OBB дочерних мешей ноды `collider`, создаются вместе с LOD0.
- Ночь: `emissiveIntensity = uNfrNight × 0.8 × (0.75…1 по uNfrWin)`. Светятся окна, плафоны, надписи, афиша, подсветка колонн и фасадов. Пятна света на земле (`pools`) рисуются одним аддитивным InstancedMesh, как у фонарей. Тени отбрасывают и принимают.
- `?landmarks=0` выключает модели, `window.__landmarks` даёт отладку (`info()`, `stats`).
- Стоимость: театр LOD0 и цирк LOD1 в кадре — 8 draw calls (+ теневой проход) и ~50 тыс. треугольников, плюс 1 вызов на пятна света. Вне ~1.1 км от объекта стоимость нулевая.

## Как добавить новый ориентир

1. Найти объект в OSM: id здания (`w…`/`r…`) или узла.
2. Собрать референсы: `cd pipeline && uv run python landmark_refs.py <id> --lat .. --lon .. --radius <полуразмер> --target-h <высота центра кадра>`. Посмотреть `crops/` и ортофото.
3. Написать `assets/scripts/landmarks/<id>.py` с функцией `build(lod) -> (meshes, collider_boxes, info)`; за образец взять `drama_theatre.py` или `circus.py`. В `info` положить `footprint` (локальные [x, z] glTF), `extraFootprints`, `pools`, `size`. Перёд модели — Blender +Y.
4. Собрать: `blender -b --python assets/scripts/landmarks/build_landmark.py -- <id> assets/build/landmarks/<id> --preview`, затем `sh assets/scripts/landmarks/pack_landmark.sh assets/build/landmarks/<id> <id>`.
5. Добавить запись в `landmarks.json`: x, z, rotY, ground, suppress. Запустить `python3 assets/scripts/landmarks/make_manifest.py`.
6. Сверить с панорамами: `uv run python landmark_compare.py <id> --crops 3,7,12` → `blender -b --python assets/scripts/landmarks/compare_render.py -- data/processed/landmarks/<id>_cams.json` → `uv run python landmark_compare.py <id> --crops 3,7,12 --compose`. Положение лучше уточнять триангуляцией приметных точек по нескольким панорамам: контуры OSM в центре часто сняты по заваленным крышам.
7. Пересобрать мир (`build_world.py`). Игре больше ничего не нужно.

## Известные ограничения

- Фигура Ленина стилизованная (лепка из примитивов), лицо и складки пальто не проработаны. Барельеф фронтона театра условный.
- Афиша цирка — абстрактный градиент без конкретного шоу.
- Площадка перед театром и цирком — это покрытия OSM (`areas`). Где мощения в OSM нет, у ступеней видна трава.
- Окна запечены одной картой свечения: горят все сразу, доля зависит только от часа.
