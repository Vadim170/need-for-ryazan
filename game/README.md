# Need for Ryazan — игра (Этап 0 скелет + Этап 1: загрузка мира)

TypeScript + Vite + Three.js + Rapier (`@dimforge/rapier3d-compat`). Тестовый мир: плоскость 2×2 км с сеткой,
коробки-«здания», трамплин, холм (heightfield), ящики, стойки вдоль прямой для ощущения скорости.

## Запуск
```
cd game
npm install
npm run dev         # http://127.0.0.1:5173
npm run build       # tsc --noEmit + vite build
npm run typecheck
```
Миры: по умолчанию грузится `/world/` (`game/public/world/`, формат — `docs/world-format.md`); если `manifest.json` нет — тестовый мир.
`?world=test` — принудительно тестовый, `?world=synthetic` — синтетический (`node scripts/gen-synthetic-world.mjs [N=12]` пишет
`public/world-synthetic/`, 12×12 тайлов по 250 м, ~25 МБ, в git не кладём). `?spawn=N` или `?spawn=пост ДПС` (подстрока `name`) — стартовая точка из `spawnPoints`
(по умолчанию случайная), `T` — телепорт в другую случайную точку, `R` — сброс на месте.
Параметр `?debug=0` скрывает панель и FPS. Клавиша `` ` `` — показать/скрыть панель.
В консоли браузера доступен `window.__game` (car, physics, vehicleConfig…).

## Управление
| Действие | Клавиатура | Геймпад |
|---|---|---|
| Газ / тормоз (назад) | W, S / ↑, ↓ | RT / LT |
| Руль | A, D / ←, → | левый стик |
| Ручник (дрифт) | Пробел | A / B |
| Нитро | Shift | X / RB |
| Взгляд назад (удерживать) | C | LB |
| Сброс (поставить на колёса) | R | Back/View |
| Звук вкл/выкл / гудок | N / H | — |
| Карта мира (быстрый переезд кликом) | M | — |
| GTA-режим: выйти/сесть/угнать, пешком, оружие, полиция | F, WASD, мышь… | Y… — см. `docs/stage3/gta-mode.md` |

## Координаты
1 единица = 1 м. Конвейер: x = восток, y = север, высота — вверх.
Three.js (Y вверх): `three.x = x`, `three.y = высота`, `three.z = -y` (север = −Z, юг = +Z).
Функции: `src/world/world-coords.ts`. Локальные оси машины: вперёд −Z, вправо +X, вверх +Y.

## Архитектура (`src/`)
- `main.ts` — сборка всего и игровой цикл.
- `core/` — `loop.ts` (rAF), `time.ts` (фиксированный шаг, damp/lerp), `input.ts` (клавиатура + Gamepad API).
- `render/renderer.ts` — рендерер, солнце с каскадными тенями (`sun-shadow.ts`), IBL неба, туман/дымка (`atmosphere.ts`), пост-обработка (`post.ts`), пресеты качества (`quality.ts`), PBR-текстуры (`textures.ts`) — см. «Реализм»; небо/время суток — «День и ночь».
- `physics/world.ts` — обёртка Rapier: фиксированный шаг 60 Гц, интерполяция отрисовки (`track(body, object)`), `groundHeightAt`.
- `vehicle/` — `config.ts` (ВСЕ параметры тюнинга в одном объекте, правятся в lil-gui на лету), `vehicle.ts` (физика), `car-visual.ts` (заглушка-модель).
- `camera/chase-camera.ts` — следящая камера: сглаживание, FOV от скорости, тряска, взгляд назад, учёт направления скорости при заносе.
- `audio/` — звук (docs/stage2/audio.md): `game-audio.ts` (адаптер игры: старт по жесту, N — mute, `setWeather/thunder/setSeason`),
  `audio-system.ts` (граф), `engine-audio.ts` + `engine-worklet.ts` (двигатель: гранулярный синтез из записей, пресеты
  `?engine=velvet|aggressive|stock`), `vehicle-sfx.ts`, `environment.ts` (реверб по застройке), `ambience.ts` + `city-zones.ts`
  (город), `gta-audio.ts`; лаборатория офлайн-рендеров — `/audio-lab.html`.
- `debug/debug-panel.ts` — lil-gui + stats.js. `hud/hud.ts` — скорость, обороты, передача, нитро.
- `world/test-world.ts` — тестовый мир.
- `world/city-world.ts` — реальный мир: manifest, коллайдер рельефа (Rapier heightfield из `heightmap.f32`; раскладка: heights
  column-major, `index = col*(rows)+row`, col → +X, row → +Z; проверено `__game.city.checkTerrain()` — ошибка < 2 мм на асимметричном рельефе),
  стриминг тайлов по расстоянию до машины (загрузка < 600 м, выгрузка > 800 м, ≤ 3 одновременно, ближайшие первыми; при выгрузке
  dispose геометрий и удаление коллайдеров), trimesh-коллайдеры из ноды `building_colliders` (не рисуется), материалы по имени.
- Рельеф рисуется игрой из `heightmap.f32` (меш на тайл, та же триангуляция, что у Rapier); нода `terrain` из glb игнорируется и не нужна.
  Любая нода с `extras.collider=true` (или имя `*_colliders`: `building_colliders`, `bridge_colliders`) → trimesh, не рендерится.
  Неизвестные материалы → нейтрально-серый (расширять `world/materials.ts`).
- `world/materials.ts` — материалы по имени glTF: шейдеры в мировых координатах с PBR-текстурами (KTX2-массивы, `render/textures.ts`) и процедурными масками, общие на все тайлы.
  Подробнее — раздел «Слои мира» ниже.
- `world/props.ts`, `world/prop-meshes.ts` — пропсы (деревья, фонари, светофоры, машины, ограды…), см. «Слои мира».
- `hud/world-map.ts` — **карта мира (M)**: полноэкранная, тайлы `public/world-map/{scheme,sat}/{z}/{x}_{y}.webp` (256 px, 4 уровня 8/4/2/1 м/px; схема — тёмная GTA-стилистика,
  спутник — Яндекс 0.5/2 м), перетаскивание, колесо/щипок/+−, `F` или кнопка — схема/спутник, подписи улиц (сокращённые, по масштабу), районы/парки (`labels.json`),
  маркеры: игрок (стрелка с курсом), брошенная машина (пешком), ориентиры К/Т/Д/Ц/Л/М/С, станции Ж, полиция П, больницы +, спавн-точки; под курсором — x/z и ближайшая улица.
  ЛКМ — быстрый переезд, ПКМ — путевая точка (ромб на карте и миникарте). Пока карта открыта — игра на паузе (физика/системы не шагают, мир стримится).
  Карта строится `cd pipeline && uv run python build_map.py` (≈1 мин, ~30 МБ: схема 16 МБ + спутник 10 МБ; `--no-sat`, `--no-scheme`, `--labels-only`) из roads/graph.json, rail/net.json,
  OSM (здания, вода, парки, леса) и `data/processed/ortho/yandex_*.tif`. Лежит вне `public/world/`, пересборка мира её не стирает; не в git.
- `world/fast-travel.ts` + `world/road-index.ts` — быстрый переезд: на машине — ближайшая точка оси дороги (граф дорог), правая полоса двусторонних, курс вдоль дороги (по стороне клика);
  пешком — ближайший узел пешеходного графа (`people/walk.json`, 40→150→600 м), иначе рельеф; в воде — ближайшая суша. Затемнение «ЗАГРУЗКА…», тело сразу переставляется
  (физика на паузе), `city.preload(250 м)` дожидается тайлов и коллайдеров, высота уточняется лучом по коллайдерам, скорости сброшены, камера `snap`. Пешеходы/трафик/поезда
  заселяются вокруг новой позиции сами (кольцевой спавн).
- `hud/minimap.ts` — миникарта (canvas, правый верх): дороги из `roads/graph.json` вокруг машины, вперёд = вверх, сетка-бакеты, 15 Гц.
- Спавн: `heading` из контракта (0 = на север, по часовой) → yaw = −heading. Туман 150–720 м скрывает край стриминга; тень солнца следует за машиной.
- Отладочная панель показывает draw calls, треугольники, число тайлов и треугольников коллайдеров.
- `window.__game`: `city`, `frame(dt,t)` (шаг кадра вручную — в скрытой вкладке rAF не идёт), `override.v = {throttle:1}`, `teleport(next)`, `spawns`.

## Слои мира (рендер)
**Ноды тайла.** Многоматериальные ноды (`roads`, `sidewalks`, `areas`, `buildings`) при загрузке склеиваются в один меш на ноду:
номер исходного материала — атрибут `aKind`, шейдер ветвится по нему. Итого ~7 draw calls на тайл вместо ~15.
- `roads`: асфальт с шумом и заплатками (осевую теперь рисует `markings`, не шейдер). `road_junction` — тот же шейдер.
- `markings` (`road_marking`): белая краска, износ по UV (v — метры вдоль линии) + мировой шум.
- `sidewalks`: `sidewalk` — плитка 0.5 м вперемешку с кварталами асфальта; `curb` — бетон со швами через 1 м, грязь снизу.
- `areas`: парковка (асфальт), плитка «кирпичиком» (2 цвета), дорожки (светлый асфальт), детплощадки (резина, красно-зелёная),
  газон (полосы покоса), грунт. `bridges` (`bridge_concrete`) — бетон с подтёками.
- `buildings`: базовый тон — вершинный атрибут `color` (по типу, `BUILDING_BASE`); **цвета фасадов** позже = перезаписать `color`
  у вершин здания. Окна — процедурная сетка; ночью ~35% окон светятся (`nfrEmissive × cityUniforms.uNfrNight`).
- **Z-fighting**: вместо polygonOffset — сдвиг глубины в вершинном шейдере (`gl_Position.z -= bias·w`, `DEPTH_BIAS` в materials.ts):
  площадки < тротуары < дороги < перекрёстки < разметка. Ближняя плоскость камеры 0.25 м (было 0.1) — точнее depth.
- Хук под CC0-текстуры: `city`-материалы `override(name, material)` по имени glTF (часть с подменой не склеивается).
- `cityUniforms.uNfrNight` (0..1) — общий «ночной» uniform: окна зданий, плафоны фонарей.

**Пропсы** (`props/{ix}_{iz}.json`) грузятся вместе с glb тайла и выгружаются вместе с ним. Рендер — глобальные `InstancedMesh`-пулы
по (вид, LOD): ~32 пула на весь мир, не зависят от числа тайлов. Пулы пересобираются, когда камера сдвинулась > 4 м / повернулась
> 4.6° / изменился набор тайлов: тайлы вне фрустума (с запасом 40 м) пропускаются, тайл целиком в одной LOD-зоне копируется блоком,
на границе зон — поштучно. Пересборка 0.3–2 мс (CPU), пул растёт удвоением. Модели — процедурные low-poly (`prop-meshes.ts`),
одна геометрия на модель с вершинными цветами и флагами (`aFlag`: тонировка цветом инстанса / свечение ночью / секция светофора):

| Вид | Модель, треугольники | LOD |
|---|---|---|
| деревья (берёза, тополь, клён, липа, сосна) | ствол + 2–4 «шапки» с шумом / ярусы конусов, ~150–260 | < 150 м полная, < 680 м упрощённая (~30), дальше нет |
| куст | 2 шапки, ~160 | < 90 м / < 300 м |
| фонарь | опора + консоль к дороге + плафон (светится ночью) | < 450 м |
| светофор | опора + 3 секции; при `lanes ≥ 3` — Г-образная консоль над полосами со второй головой | < 300–350 м |
| остановка, контейнерная площадка, детплощадка (4 модели по `variant`, цвет по variant), лавочка, урна | коробки/цилиндры | 100–350 м |
| `parked_car` | процедурная «Лада»: универсал или седан по `seed`, цвет по `seed` (палитра с весами), ~300 / 24 треугольника | < 130 м / < 420 м |
| ограды и ограждения (`fences.ts`) | панель (заполнение + перекладины) по сегменту, идёт по рельефу; столбы через 2–3 м; блоки «Нью-Джерси» | 220–320 м |
| улица: клумбы (круг/прямоугольник), боллards, шлагбаумы (тумба + стрела по `armDir`), парковые и двойные фонари, подъезды (крыльцо, дверь, козырёк, светильник), витрины с вывесками | low-poly | 120–450 м |
| декали дорог (`decals.ts`): люки, ливнёвки у бордюров, следы шин перед перекрёстками, заплаты | квад, прозрачный, сдвиг глубины | < 150 м |

**Ограды** (`fences.ts`): узор заполнения — шейдер с alpha-test (вдали — дизеринг, без мерцания): сварная секция из профтрубы
(зелёная/чёрная), кованая с пиками (центр, Кремль, сталинки, храмы), рабица (гаражи, частный сектор), профнастил, бетонный
ПО-2 с ромбами (промзона), штакетник, кирпич со столбами, штукатурка/побелка (Кремль), низкие заборчики с дугами и разноцветный
штакетник (`lawn_fence`), пешеходные ограждения (`ped_fence`: красно-белое, серое, зелёное, декоративное), отбойник W
(`guardrail`), «Нью-Джерси» (`jersey_barrier`). Стиль: поле `style`, иначе по окружению (растр покрытий тайла `surface-mask.ts`:
архетипы зданий v2 в радиусе 25 м — школа, гаражи, промзона, частный дом, сталинки/храмы, торговля; газоны, детплощадки);
цепочка сегментов с общими концами — один стиль. Ворот нет (разрывы в данных).

**Улица**: витрины — стекло (днём тёмное, ночью тёплый свет), вывеска с текстом `signText` в атласе 2048² (`signs.ts`: canvas →
ячейка 384×48, ≤ 210 ближайших в радиусе 140 м, LRU, ≤ 6 ячеек за кадр через `copyTextureToTexture`; без ячейки — фирменный
цвет). Подъезды — модель с крыльцом, опущенная на `0.6 − stepsHeight`. Ночью светятся (`cityUniforms.uNfrNight`) плафоны,
окна витрин, вывески.

**Трава** (`grass.ts`): два кольца GPU-пучков (≤ 21 м — 8 травинок × 2 сегмента, 21–70 м — крупные пучки), 2 draw calls, 0 CPU в
кадре: сетка привязана к миру, высота — из текстуры heightmap в вершинном шейдере, ветер, плавное затухание, ранний выход для
пустых пучков и позади камеры. Где расти — окно маски 192×192 м (0.5 м) вокруг камеры из масок тайлов: газон `area_grass` —
густо/коротко; рельеф без покрытий — по зелёности спутника (`public/world-veg/veg.png`, 4 м; строится
`cd pipeline && uv run python build_vegmask.py` — лежит вне `public/world/`, чтобы не стираться пересборкой мира); грунт —
редко; на дорогах/тротуарах/плитке/парковках/площадках/в зданиях — нет. У бордюров, стен и оград — высокие сорняки, на склонах
(градиент heightmap) — высокая некошеная трава, пятна цветов (одуванчики/клевер на газонах, ромашки/васильки/пижма на пустырях).
Шейдер травы компилируется асинхронно (`compileAsync`), до готовности трава скрыта.

**Поверхности**: асфальт — трещины, колея и масляная полоса по полосам (ширина ленты из градиента UV), песок у бордюра, следы
шин и пятна на перекрёстках; тротуары — листья и окурки; газон и рельеф — выгоревшие пятна, клевер, вытоптанная земля.

**Ломаемые пропсы** (`breakables.ts`, логика в `props.ts`): фонари (все типы), опоры светофоров, боллards, секции оград
(по одной), пешеходные ограждения, заборчики, отбойники, «Нью-Джерси», остановки, контейнерные площадки, лавочки, урны, калитки
(`fence_gate`). Ломаемые статические коллайдеры шлют события сил контакта (Rapier `CONTACT_FORCE_EVENTS`, `PhysicsWorld.onPostStep`);
после шага разбирается реальный контакт с динамическим телом (машина игрока, сдвинутые машины парковки, трафик): скорость
сближения до удара = |v·n| + F·dt/m; если она выше порога класса (фонарь 28 км/ч, светофор 25, боллард 20, ограда 15, пешеходное 14, отбойник 60, бетонный
блок 30 — сдвигается, лавочка 5…), статический коллайдер убирается, инстанс прячется, на его месте — динамическое тело реальной
массы в его текущей позе (фонарь 250 кг, секция ограды 18 кг/м, боллард 40 кг, блок 900 кг/м); опоры валятся от основания
(составной коллайдер: опора + консоль + голова). Машине возвращается скорость сближения за вычетом обмена импульсом с обломком
и потери на разрушение (`loss`, км/ч) — без «стены» и без ранних поломок (ломается только при реальном касании); ниже порога —
стена. Проверено: фонарь 40 → ~25 км/ч и падает; 15 км/ч — держит, машина останавливается. Сломанный фонарь
гаснет, светофор тёмный. Обломки — до 40 (старые исчезают), > 220 м или 120 с — исчезают; пропс остаётся сломанным, пока тайл не
перезагрузится. Обломки рисуются отдельными маленькими пулами по виду, группа коллизий 3 (луч камеры их не видит).

**Припаркованные машины** стоят на колёсах: высота и наклон по поверхностям под 4 колёсами (рельеф + дорога 0.05 / тротуар 0.15 /
площадка 0.03), трава под машиной и вокруг (5 × 2.3 м) вырезана.

**Запросы для других систем**: `city.props.queryObstacles(x, z, r, out)` (круги/повёрнутые прямоугольники твёрдых пропсов,
сетка 8 м на тайл, ~4 мкс) и `city.props.isBlocked(x, z, pad)` — для пешеходов. Неизвестные типы пропсов пропускаются с
одним предупреждением в консоли.

Светофоры: своя циклограмма 30 с (фаза на перекрёсток — кластеры < 45 м, поперечные подходы сдвинуты на полцикла).
Внешнее управление (для `src/traffic/signals.ts`): `city.props.setSignalSource((light) => 0|1|2|3|4|null)` — 0 красный, 1 жёлтый,
2 зелёный, 3 красный+жёлтый, 4 жёлтый мигает, null — своя циклограмма; вызывается ~5 Гц для светофоров загруженных тайлов
(`city.props.trafficLights`: x, y, z, rotY, lanes).

Физика пропсов: статические коллайдеры для тайлов ближе 120 м к машине (снимаются дальше 200 м, создаются ≤ 500 за кадр):
стволы деревьев и опоры фонарей/светофоров — цилиндры; остановки, контейнерные площадки, машины, ограды и стены — боксы.
Лавочки, урны, кусты, детплощадки — без коллайдеров. Группа коллизий пропсов `PROP_GROUPS` — `groundHeightAt` (камера) их не видит.

**Производительность** (Apple M4, Chrome, 1920×1080, pixelRatio 1, тени 4096; мир загружен целиком в радиусе 600 м; кадр с
синхронизацией GPU через readPixels):

| Место | draw calls | треугольники | пропсов в кадре / загружено | кадр, медиана |

| площадь Победы | 165–188 | 0.6–0.67 M | 2.7k / 9.4k | 6.4–7 мс |

## Погода и сезоны (`src/render/weather*.ts`, docs/stage3/weather-seasons.md)
`?weather=clear|cloudy|overcast|rain|storm|fog|snowfall` (фиксированно; `random` или без параметра — случайный цикл по климату
Рязани), `?season=summer|autumn|winter|auto` (auto — по игровой дате; зима/лето/осень переставляют дату на 20.01/15.07/10.10, если нет

**Контракт для материалов (всем агентам):**
- `weatherUniforms` (`render/weather.ts`) — глобальные `{value}`: `wetness`, `puddles`, `rainIntensity`, `snowIntensity`, `snowCover`,
  `slush`, `fog`, `windDir` (vec2) + `windStrength`, `season` (0 лето … 0.5 осень … 1 зима), `cloudCover`, `lightning`; плюс
  `trail`/`trailWin` (карта следов шин), `surf`/`surfWin` (маска покрытий у камеры из grass.ts; A — близость к краю дороги).
  Пишет только `WeatherSystem`; читать можно откуда угодно (кладите прямо в `shader.uniforms`).
- `applySurfaceWeather(material, kind)` — ОДИН вызов после создания материала; kind: `road`, `sidewalk`, `area`, `terrain`,
  `roof`/`wall` (здание: крыша/стена по нормали), `vegetation` (кроны с `varying float vFlag`, flag 1 = листва), `pine`, `car_paint`
  (трафик, instancing, шапка из дробной части `aLamp.z`), `player_car`, `prop`. Хелпер оборачивает уже заданный `onBeforeCompile`
  и дописывает `customProgramCacheKey`, вставки — перед `#include <fog_vertex>` и `#include <emissivemap_fragment>`: свой код
  материала можно менять как угодно, только не удаляйте эти чанки. Необязательный хук: в своём фрагментном коде можно
  присвоить глобальной `wxEdgeHint` (0..1, близость к бордюру) — иначе берётся из маски.
- `CityMaterials.override(name, mat)` применяет погоду автоматически (`weatherKindFor(name)`).
- `weatherGrip.value` — множитель сцепления шин (vehicle.ts); трафик — `vf/T/b` машин (WeatherSystem.updateTraffic);
  пешеходы — `weather.pedestrianFactor` и `people.setWinter(weather.winterClothes)` (main.ts); звук — `audio.setWeather({rain,
  snow, wind, storm})` и `audio.thunder(delaySec, intensity)`, если есть.
- Небо/свет: `DayNight.paletteHook` (облачность гасит солнце, серое небо, туман сокращает `fogFar`, молния — вспышка).

## Пешеходы
`src/people/` (подробно — [docs/stage2/people.md](../docs/stage2/people.md)). Граф `public/world/people/walk.json` строит пайплайн
(`pipeline/world/walk_export.py`); нет файла — нет пешеходов. До 1300 агентов в кольце 40–300 м от машины (плотность по зонам и
`pedestrianDensityCurve` времени суток), процедурные low-poly люди (~350 треугольников, инстансинг, анимация в вершинном шейдере,
2 draw call). Переходы: фазы светофоров из `traffic/signals.ts` (`pedestrianWalk`), без трафика — таймер; на нерегулируемых — ждут
машины. Машина игрока: прогноз траектории на 1.5 с, реакция с задержкой 0.2–0.5 с, шаг в сторону от траектории только на тротуар/газон
(не на проезжую часть), на переходе — бегом к ближайшему бордюру; при ударе — рэгдолл Rapier (пул 8, 11 тел), потом встаёт и грозит
кулаком. `?people=0` — выключить, `?people=N` — максимум агентов. Отладка: `__game.people.system` (`stats`, `debugAgents()`,
`showGraph(__game.rc.scene, x, z)`, `debugLineup(x, y, z)`).

## Трафик и общественный транспорт (`src/traffic/`, docs/stage2/traffic.md)
Данные: `world/traffic/net.json` + `geom.bin` (граф полос SUMO, светофоры, маршруты ОТ; формат — docs/world-format.md). Нет файла — трафика нет.
`?traffic=0` — выключить, `?traffic=N` — потолок машин (по умолчанию 600, плюс ≤ 16 автобусов/троллейбусов/маршруток).
- Симуляция в фиксированном шаге физики (IDM, светофоры, приоритеты SUMO, перестроения, случайные повороты по классу дороги), отрисовка — InstancedMesh по видам × 2 LOD + колёса; ближние машины — кинематические тела Rapier; удары — по реальным контактам и массам (обмен импульсом: машина трафика при ощутимом толчке становится динамической, ударивший не «упирается в стену»; чуть сдвинутая возвращается в поток, сильно — глохнет с аварийкой).
- `traffic.setDensityFactor(f)` — плотность (main.ts: `trafficDensityCurve(час)`), `traffic.setHeadlights(on)` — фары (по `headlightsWanted`), `traffic.setMaxVehicles(n)`,
  `traffic.setPedestrianSource((x, z, r, fn) => …)` — пешеходы, перед которыми тормозить (main.ts: `people.system.forEachNear`).
- **Светофоры** (`traffic.signals`, `SignalController`):
  - `getSignalState(junctionId, linkIndex)` → символ SUMO (`G` `g` `y` `r` `u` = красный+жёлтый, `o`/`O` — выключен);
  - `getApproachColor(junction, edge)` → 0 красный, 1 жёлтый, 2 зелёный, 3 красный+жёлтый, 4 мигает жёлтый; `approaches(junction)` — подходы (стоп-линия, направление, число полос);
  - `pedestrianWalk(junction, edge)` → `true` — «рукав» (ребро входа или выхода, id SUMO) можно переходить (все машины с него и прямые в него стоят на красном), `false` — нельзя, `null` — узел без светофора;
  - `propSource()` → функция для `city.props.setSignalSource` (пропсы светофоров сопоставляются подходам по положению и направлению).
- Кинематика: сглаженные пути (Катмулл–Ром), «велосипед» без скольжения (передняя ось по пути, задняя — трактриса, руль на передних колёсах), S-кривая смены полосы с поворотником заранее, разгон/торможение по типу с ограничением рывка, скорость в повороте по кривизне, крен/тангаж кузова (уклон дороги + пружина при разгоне/торможении/повороте) у машин ближе 150 м.
- Миникарта рисует машины точками (жёлтые — легковые, синие — автобусы/ГАЗели): `minimap.traffic`.
- Отладка: `__game.traffic.stats()`, `.near(x, z, r)`, `.lights(x, z, r)`, `.buses()`, `.overlaps()`, `.sim.explain(v)`; `__game.trafficSystem` — объект `Traffic`.

## Железная дорога (`src/rail/`, docs/stage2/rail.md)
Данные: пути в тайлах (ноды `railway`/`railway_colliders`, материалы ставит `installTrackMaterials(city.mats)` до загрузки тайлов) и граф
`world/rail/net.json` (формат — docs/world-format.md). Нет файла — поездов нет. `?rail=0` — выключить.
- Поезда: электрички (ЭД9/ЭП2Д-подобные, 4–10 вагонов, красно-серая или сине-белая ливрея), пассажирские (ЭП2К-подобный + 10–15
  вагонов РЖД), грузовые (2ЭС5К-подобный из двух секций + 30–60 цистерн/полувагонов/крытых), маневровые на подъездных путях.
  Процедурные low-poly модели, InstancedMesh на тип вагона и тележки, огни по `timeUniforms.nightFactor`.
- Расписание: линии «портал → портал» (порталы — выходы путей за край мира; поезд появляется и исчезает в 1.5 км за краем, в тумане),
  2–4 поезда за 10 мин на направление; электрички стоят у платформ Рязань-I/Рязань-2/203 км 30–60 с; в зоне станций 40 км/ч, на перегоне
  80–110 км/ч; встречный по тем же путям не выпускается, на слиянии уступает дальний.
- Переезды: огни мигают за ~30 с до подхода, шлагбаумы опускаются через 7 с; закрытый переезд — «стоп-коробка» для трафика
  (`traffic.extraObstacles = rail.crossingObstacles`, main.ts).
- Физика: вагоны у игрока (≤ 160 м) — кинематические тела Rapier (группа бит 4); удар — машину отбрасывает импульсом. Пути и балласт —
  trimesh-коллайдеры (трясёт на рельсах).
- Звук: `rail.onEvent(cb)` — `horn` (переезд, игрок у пути, отправление), `crossing` (закрыт/открыт), `spawn`/`despawn`, `crash`, `brake`;
  `rail.rumble` 0..1 — грохот ближайшего поезда.
- Миникарта: пути — штрих, поезда — оранжевые линии (`minimap.rail`).
- Отладка `__game.rail`: `stats()`, `lines()`, `trains()`, `crossings()`, `spawn(kind, line, {s, v, cars})`, `spawnNear(x, z, kind, sec)`,
  `shuttle(i)`, `clear()`, `where('Рязань')`; `sim.autoSchedule`, `sim.frequency`.

## Модель машины
Своя raycast-подвеска, а не `DynamicRayCastVehicleController` Rapier: нужен полный контроль над кривой сцепления,
ручником/дрифтом, ассистами и нитро, а встроенный контроллер даёт только базовое трение шин
и плохо расширяется под аркадные хаки. Цена — больше кода, но всё в одном `step()`.

Каждый физический шаг (60 Гц): 4 луча (пружина + демпфер + отбойник + анти-ролл) → сила шин
(латеральная — упрощённая формула Пасейки по углу увода, продольная — привод/тормоз/сопротивление качению, эллипс трения:
газ в повороте уменьшает боковое сцепление) → двигатель (кривая момента, РПМ, автоматическая КПП 6 передач + задняя,
отсечка/ограничитель) → аэродинамика и прижимная сила → ассисты (авто-контрруль, стабилизация на прямой,
ограничение угла заноса, доворот руля) → нитро.
Руль зависит от скорости. Привод задний (`driveFrontShare` = 0).

## Что заглушка
- Модель машины — коробки и цилиндры (позже Lada Largus, glTF).
- Звук: см. docs/stage2/audio.md (сэмпловый двигатель, город, погода, GTA).
- Рендер: `WebGLRenderer`. TODO: `WebGPURenderer` из `three/webgpu` с фолбэком на WebGL2 (нужны async-init и TSL; отложено).
- Пропсы и машины на парковках — процедурные low-poly (без файлов ассетов); деревья — v2 с импостерами (docs/stage3/realism.md).
- Тест-мир — не карта Рязани. Тайлы читаются только обычным GLTFLoader (без Draco/meshopt). Нет следов шин/дыма/частиц, motion blur, повреждений.
- Колёса не имеют модели пробуксовки (скорость вращения = скорость земли).

## Известные ограничения
- Тюнинг дрифта и ощущений сделан только численными симуляциями без живого прохождения — нужна обкатка руками.
- Масса/габариты в панели применяются только при пересоздании машины (код).
- Бандл ~5 МБ (Three + Rapier WASM inline), потом нужен code-splitting.
